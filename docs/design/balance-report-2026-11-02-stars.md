# 数值验证报告（三）：星级平衡原则（2026-11-02）

> 检验 [card-design.md 第 0 节](game-design.md#4-平衡原则) 的星级平衡原则在现有 1★/2★ 数据上是否成立。
>
> ⚠️ **时效**：
> - 用的是已决定的新规则：反噬双方结算并走伤害流程、坚固求和、平局 = 连续 7 次战力不变或 20 轮无人阵亡。
> - 圣水按新版：仅战前时机，+2 战力。
> - 数值或规则改动后，具体数字失效。
> - 引擎是一次性的纯逻辑副本（与 Godot 对拍 400 场完全一致，已清理）。

## 方法

- **随机摆位**：站位顺序和装备分配都随机。
- **较优摆位**：在该阵容（角色加装备的组合）所有可能的站位和装备分配中，选出对一批对手平均表现最好的那一种。对手是同一批对阵里随机摆位的阵容。不针对具体对手，模拟"不知道对方怎么摆"时的合理摆法。
- **计分**：胜 1、平 0.5、负 0。下文的"平均分"都是第一方的平均分。

## 1. 同总星级：多个低星 vs 少量高星（裸卡）

| 对阵（总星相同） | 少而高星方 随机 / 较优 | 少方占优 / 持平 / 多方占优（按阵容组合计） |
|---|---|---|
| 1×2★ vs 2×1★（2 星） | 0.563 / 0.533 | 53% / 7% / 40% |
| 1★+2★ vs 3×1★（3 星） | 0.539 / 0.522 | 51% / 4% / 45% |
| 2×2★ vs 4×1★（4 星） | 0.609 / 0.569 | 61% / 2% / 37% |
| 3×2★ vs 6×1★（6 星，抽样，±0.03） | 0.512 / 0.466 | 42% / 19% / 39% |

**结论**：

- 2–4 星时**少而高星的一方略占优**（0.52–0.61）。
- 6 星时大致持平，较优摆位下 6×1★ 一方反而略好：人越多，集结、振奋和摆位的收益越大。
- 和你说的"2 个 1 星打 1 个 2 星应有优势"相反（目前 2×1★ 方只得 0.44–0.47），但和你给的均值 6/13 一致，原因见下面的"总和守恒"。

**总和守恒**：两个都没有技能的单位交战，双方都恰好损失较小的那个战力。所以白板之间打，就是比双方战力总和，多出的部分就是胜方剩下的战力。

用你的均值 6/13/21/30/40 套进去：

| 对阵 | 战力总和 | 结果 | 与你的预期 |
|---|---|---|---|
| 2×1★ vs 1×2★ | 12 vs 13 | 2★ 略胜 | 相反 |
| 1★+3★ vs 2×2★ | 27 vs 26 | 持平 | 一致 |
| 2×2★ vs 4★ | 26 vs 30 | 4★ 胜 | 一致 |

均值差分是 7、8、9、10，每星的价值随星级递增，所以低星多人方在纯身材上一直略吃亏。要让"2×1★ 有优势"成立，1★ 的群体技能（集结、振奋）在两人队里的收益要超过 1 点战力；目前还不够（0.44–0.47）。人数多到 6 个时，群体技能的收益才追上来。

## 2. 装备星级与角色星级

| 对阵（总星相同，A 用装备补星） | A 随机 / 较优 | A 占优的组合比例 |
|---|---|---|
| 1★角色+1★装备 vs 2★角色（单人） | 0.178 / 0.178 | 12% |
| 1★角色+2★装备 vs 2★角色+1★装备（单人，3 星） | 0.253 / 0.253 | 13% |
| 2×(1★+1★装备) vs 2×2★（4 星） | 0.110 / 0.109 | 8% |
| 3×1★+3件1★装备 vs 3×2★（6 星） | 0.041 / 0.051 | 2% |
| 3×2★+1件2★装备 vs 3×2★+2件1★装备（同人数，8 星） | 0.457 / 0.497 | 41% |

**结论**：

- **装备的一颗星远不如角色的一颗星**。按有效战力算，装备一星大约只顶角色一星的 1/3：
  - 1★ 装备平均约 2–2.5，木剑 5；1★ 角色约 6。
  - 2★ 装备平均约 4，铁剑 8；2★ 角色约 13。
- **人数相同时，装备之间是平衡的**：1 件 2★ 装备 ≈ 2 件 1★ 装备（较优摆位 0.497）。
- 这是"装备 vs 角色"的折算问题，需要你决定原则怎么定（见第 5 节）。

## 3. 星差、方差与摆位

随机阵容：3 个角色各为 1★ 或 2★，每人 50% 概率带 1★/2★ 装备，总星 3–12。共抽 6000 对。

| 星差 | 多星方平均分 | 多星方占优比例 | 阵容对之间的标准差 |
|---|---|---|---|
| 0 | 0.48 | 43% | 0.37 |
| +1 | 0.64 | 63% | 0.35 |
| +2 | 0.76 | 77% | 0.30 |
| +3 | 0.85 | 86% | 0.26 |
| +4 | 0.92 | 94% | 0.18 |
| +6 | 0.99 | 100% | 0.04 |

按星级水平分开（取双方中较低的总星）：

| 水平 | 同星时胜率标准差 | 多 1 星平均分 | 多 2 星平均分 | 较优摆位比平均摆位多得的分（平均 / 最大） |
|---|---|---|---|---|
| 低（3–5 星） | 0.39 | 0.68 | 0.79 | 0.08 / 0.19 |
| 中（6–7 星） | 0.37 | 0.62 | 0.74 | 0.16 / 0.34 |
| 高（8+ 星） | 0.36 | 0.59 | 0.71 | 0.17 / 0.28 |

**结论**：

- ✅ 星差越大，胜率越悬殊，曲线平滑单调。
- ✅ 星级越高，同样的星差越不决定胜负（多 1 星：0.68 → 0.59）。
- ✅ 摆位和装备分配带来的增益随星级上升（0.08 → 0.17），符合"有配合胜率更高、适配性带来更多增益"。
- ⚠️ 同星时的胜率标准差并没有随星级变大（0.39 → 0.36）。单场对阵本来就很悬殊（常常是一边倒），这个指标不敏感。更能说明问题的是上面"多 1 星"那一列。

## 4. 种族平衡

### 4.1 三张同族 2★（可重复）

|---|---|---|---|---|---|
| 动物 | - | 0.65 / 0.76 | 0.44 / 0.40 | 0.63 / 0.68 | 0.84 / 0.80 |
| 精灵 | 0.34 / 0.27 | - | 0.39 / 0.30 | 0.57 / 0.54 | 0.52 / 0.51 |
| 人族 | 0.54 / 0.59 | 0.62 / 0.69 | - | 0.54 / 0.51 | 0.94 / 0.95 |
| 自然 | 0.38 / 0.33 | 0.43 / 0.47 | 0.46 / 0.52 | - | 0.64 / 0.61 |
| 神族 | 0.17 / 0.14 | 0.47 / 0.47 | 0.05 / 0.05 | 0.37 / 0.36 | - |

|---|---|---|---|---|

### 4.2 同族 2×1★ + 2×2★（总 6 星）

| 人族 | 动物 | 自然 | 精灵 | 神族 |
|---|---|---|---|---|
| **0.90 / 0.94** | 0.61 / 0.66 | 0.43 / 0.44 | 0.34 / 0.32 | 0.22 / 0.21 |

各族的 2★ 成员：人族 = 半精灵人、虎人、盾卫；动物 = 精灵虎、秃鹫、虎人、豪猪；自然 = 树精、秃鹫、食人花；神族 = 仙女、圣骑士；精灵 = 精灵虎、半精灵人、树精、仙女。

**结论**：

- 你举的"人族 vs 自然"（三张 2★）基本持平：0.54 / 0.51。
- 但种族整体**不平衡**。原因有两个：
  1. **集结叠加是平方增长**：每个集结单位触发时，加上全队的集结总和。人族的集结卡越多，每张卡吃到的加成越大。加入 1★ 士兵后，人族几乎全胜（0.90）。
  2. **神族 2★ 只有两张**：仙女和圣骑士，其中圣骑士没有主动技能；神族的振奋也只是线性的。
- 随机混编阵容里，各卡是平衡的（第一份报告）；不平衡只出现在**同族集中**的阵容里。羁绊暂不做，所以目前同族集中也没有额外收益。

## 5. 需要讨论的点

1. **多人 vs 高星**：现有数据和你的均值 6/13/21/30/40 都表示少人数时"少而高星略占优"（人数到 6 个时持平），与"2×1★ 应占优"的说法不一致。两个方向：
   - 以均值为准，接受 2★ 略占优；
   - 想让低星多人占优，就把低星均值往上调（比如 1★ ≈ 7），或者加强群体技能的收益。
2. **装备星级怎么折算**：
   - 如果"总星相同则胜率相当"也包括装备，现有装备大约弱了 3 倍；
   - 如果原则只在**人数相同**时比较装备（装备不占人口），现有装备内部已经平衡。
   - 我倾向后者：装备不占人口，本来就不该和角色按星等价。
3. **种族/词条平衡**：集结的平方叠加和神族 2★ 偏少，是以后做 3★/4★、羁绊时要考虑的。是否需要现在就调整 1–2★？
