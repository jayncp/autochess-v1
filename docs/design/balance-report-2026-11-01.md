# 数值验证报告（2026-11-01）

> 目的：用模拟对战检验 [card-design.md](card-design.md) 里的数值模型，理解现有 15 个角色、13 件装备的强度。
> 只针对裸卡和装备；没有三星卡、没有羁绊。原三星、圣水变体、战斗长度见 [balance-report-2026-11-01-part2.md](balance-report-2026-11-01-part2.md)。
>
> ⚠️ **时效**：基于 2026-11-01 的卡牌数据和当天决定的规则（反噬修复等，尚未在 Godot 中实现）。之后数值或规则改动后，本报告的具体数字即失效，只保留方法和结论思路的参考价值。所用的 Python 副本引擎是一次性工具，已清理；以后用正式的无头模拟器重跑。

## 1. 方法

- **引擎**：一次性的纯逻辑 Python 副本（已清理），逐行照搬 `battle_manager.gd`（不放动画的分支），卡牌数据直接解析 `card_database.gd`。
  - **对拍验证**：随机生成 1499 场对局（1–7 人，60% 位置带随机装备），与 Godot 原引擎的结果**完全一致**（胜负和每个幸存单位的最终战力）。
  - 速度：单核约 2.2 万场/秒，是实例化 Godot 战斗场景（约 32 场/秒）的近 700 倍。
  - 正式实验用的是 2026-11-01 已决定的规则：反噬两边都结算并走伤害流程、坚固求和、加回合上限。按这套规则，交换左右的结果完全对称。
- **计分**：胜 1、平 0.5、负 0。
- **有效战力**：一个只有战力、没有技能的"白板"单位，需要多少战力才能和被测卡发挥同样的作用。
  - 做法：把被测卡（或白板）放进三人队的每个位置，队友从该环境里随机抽取，与环境里的全部队伍对战；找出平均分相同时白板的战力。
  - 环境：**1★ 环境**是 5 个 1★ 角色组成的全部三人队；**2★ 环境**是 10 个 2★ 角色组成的三人队（抽样，数值有约 ±0.5 的噪声）。
  - 白板曲线有上限：1★ 环境里，白板到 16 就几乎全胜，所以 1★ 环境中高于 12 左右的有效战力不精确，标"≥"的是到顶了。2★ 环境在 44 到顶（因为致命，白板胜率最多 0.95）。

## 2. 主要结论

### 2.1 数值模型成立

- **方法自洽**：战前狂暴 v 正好等于 +v 战力；小精灵（6 战力，无技能）测得 6.0；精灵虎（7 + 战前狂暴9）测得 16.0。
- **1★ 很紧凑**：有效战力 5.1–7.0，价格都是 3。
- **2★ 约为 1★ 的 2.2 倍**：平均有效战力约 13.4。价格比是 2 倍，多出的部分可以理解为人口位置的价值。
- **你的数值顺序得到印证**：同星级下技能数值 振奋 < 集结 < 狂暴 < 腐蚀，与"每点价值"正好相反。

| 每点价值（1★ 环境、入场时机、数值 1–3） | 振奋 | 集结 | 狂暴 | 腐蚀 |
|---|---|---|---|---|
| 每点相当于多少战力 | ~1.8 | ~1.4 | 1.0 | ~0.9 |

- **时机的影响**：
  - 交战时机每次交战都触发，狂暴、腐蚀、集结的价值约为入场的 1.5 倍；
  - 战前振奋最强（还没开打就给全队加成，每点约 3）；
  - 腐蚀数值超过对方首位的战力后就浪费了：1★ 环境里腐蚀超过 4，价值基本不再增长。

## 3. 讨论结论（2026-11-01 用户答复）

| 发现 | 结论 |
|---|---|
| 食人花在所有环境都最弱 | **设计如此**。致命机制强大，需要想办法保护它，这正是致命的魅力 |
| 圣水最强 | 最初设计只有"战前"时机，测试玩家反馈弱、不好用，才加了振奋1。可能的方向：2★ 保留仅战前版本，3★ 做战前+振奋版本（变体对比见 part2） |
| 装备特殊技能替换导致负收益组合 | **确定替换**。叠加太强：致命+庇护是游戏的天花板级机制 |
| 1★ 内部强弱 | 与用户当年的测试记忆一致 |
| 木剑约为其他 1★ 装备的 2.5 倍、防爆头盔为最弱 2★ 装备 | 未讨论，留作以后调数值时参考 |

## 4. 附带发现：战斗可能无限循环（新 bug，B7）

随机对局中发现一例永不结束的战斗：P1 首位 老虎+圣水 对 P2 盾卫+狮心。

- 老虎每次交战用振奋给全队加战力，所以"连续 7 次战力不变"的平局条件永远达不到；
- 老虎的攻击打不穿盾卫的坚固4，盾卫也打不死老虎；
- Godot 没有回合上限，于是战斗无限进行，开着"跳过"时游戏会直接卡死。

已决定加回合上限（R4），重构时一并解决。

## 5. 局限

- 都是均匀随机组队，不是玩家会优化的阵容；站位也是随机的。
- 只有 1–2★ 卡，没有 3★ 和羁绊。
- 2★ 环境是抽样的，有约 ±0.5 的噪声。
