## 1. 原三星效果的实现口径

特殊技能都按"特殊技能"处理，所以装上带特殊技能的装备后会被替换掉。

| 效果 | 实现 | 依据 |
|---|---|---|
| 湮灭N | 对方全体各受 N 点伤害（走坚固/庇护） | 规则表 + Python |
| 精灵女王 | 女王在场时，己方单位的战前效果多执行一次 | Python |
| 战神 | 战神在场时，己方单位的入场效果多执行一次 | Python |
| 大王花 | 大王花在场时，己方每次腐蚀 +5。它自己的"腐蚀5"没有时机，**永不触发** | Python；时机取最新表（无） |
| 地狱之主 | 开战前把己方所有振奋（含装备）转为等值湮灭 | Python |
| 勇者 | 自身装备提供的战力 ×2 | Python |
| 神圣精灵 | 庇护 + **永久**免疫腐蚀 | 最新表（Python 是免疫一次） |
| 猎人 | 猎人在场时，对方单位每触发一次狂暴，猎人 +2 | **自行解读**（新版效果，Python 无参考） |
| 雷神 | 战斗内无效果（士气相关） | — |
| 污染源 | 每条腐蚀结算两次 | Python |
| 勇者之魂 | 战力加上一次角色的卡面基础战力 | **自行解读** |
| 模仿面具 | 战前开始时，战力变为对方卡面基础战力的最大值 | **自行解读** |
| 基因密码 | 无羁绊时只剩"替换特殊技能"的副作用 | — |
| 噬心药剂、空心 | 基础技能整体替换角色技能（空心为清空） | 已决定 R3 |

### 2.2 观察

1. **原三星强度跨度极大**：从约 10（大王花、精灵女王）到 ≥45（猛犸、大天使长、神圣精灵）。这支持拆成 3★/4★ 两档。
2. **"高身材 + 庇护"是最强组合**：
   - 猛犸去掉庇护后从约 46 掉到 25；Godot 注释里的猛犸正好没有庇护。
   - 庇护挡掉的是一整次交战伤害，所以它的价值随持有者战力增长。
3. **致命的价值随对手变强而上升**：丛林神庙在 2★ 环境 27.9，在 3★ 环境 37.7。这和"食人花需要保护、致命在后期更有价值"的设计一致。
4. **湮灭很强**：
   - 地狱之主、地狱火都名列前茅；
   - 湮灭 1 点就能打掉对方全体未用的庇护（任何大于 0 的伤害都会消耗庇护），是庇护的天然克制。这一点需要你确认是否符合设计。
5. **功能型卡在随机阵容里偏弱，在配套阵容里约翻倍**。它们的强度取决于构筑，适合放在"需要凑阵容"的档位。
6. **数值型里两张偏弱**：大将军的集结5没有时机，只能被别人统计；狼王只是高额狂暴。它们接近 2★ 的上沿。

### 5.2 解读

- 仅战前版只对"入场/交战时机且有技能"的角色有用，加成 2–4。
- 对另外一半角色完全无效：本来就是战前的，或者没有普通技能的。这解释了测试玩家觉得它"弱、不好用"。
- 如果 2★ 要保留仅战前版，它会是最弱的装备，可能需要另外的补偿。
- 仙女翅膀已经是"战前+振奋2"的 3★ 版本，强度在 3★ 装备的第一档。

## 6. 战斗长度与平局规则

6 万场随机对局：1–7 人，1–3★ 角色，60% 带 1–3★ 装备，新规则，回合上限 200。

| 指标 | 中位 | P99 | P99.9 | 最大（不含触顶） |
|---|---|---|---|---|
| 主战斗轮数 | 5 | 17 | 21 | 27 |
| 最长连续"无人阵亡"轮数 | 1 | 4 | 9 | 12 |

- 被"连续 7 次全场战力不变"判平的有 4877 场（8%），触及 200 回合上限的有 11 场（0.02%，都是 B7 这类无限战斗）。
- "无人阵亡"连段的分布：0 轮 14131、1 轮 36770、2 轮 7698、3 轮 516、4 轮 362、5 轮 210、6 轮 80、7 轮 32、8 轮 111、9 轮 78、12 轮 1。

**核实结果**：现行 Godot、资源库里的旧版和 AI 版都用"连续 7 次全场战力不变"判平；Python 用"主循环超过 100 轮"判平。所有代码和文档里都没有 10 或 30 回合的规则。

**建议规则**（待定）：

1. 保留"连续 7 次全场战力不变"，用于快速结束僵局；
2. 新增"连续 N 轮无人阵亡"判平，N 取 15–20（实测正常对局最多 12 轮）；
3. 加绝对上限 100 轮作为保险。

第 2 条正好覆盖 B7。如果 N 取 10，6 万场里只会有 1 场正常对局被误判。
