# 关卡

> 活文档：现有关卡的数据与解。解由 `just levels` 枚举得出，规则改动后重新枚举。
>
> **枚举口径**：
> - 玩家的所有摆法都算，包括只上部分角色、装备可以不用；相同的卡互换算同一种摆法。
> - 玩家是 P2。只有获胜算通过，平局不算。

## 猪突猛进

- 敌方：豪猪+毒囊 / 豪猪+剧毒之牙 / 豪猪+防爆头盔 / 豪猪+铁剑
  - 毒囊、铁剑不带特殊技能，所以这两只豪猪保留反噬4；
  - 剧毒之牙、防爆头盔会替换掉反噬。
- 玩家可用：秃鹫、食人花、半精灵人、虎人；装备 战旗、尖刺拳套。
- **912 种摆法，10 个解，通过率 1.10%**。

| 组 | 思路 | 解 |
|---|---|---|
| A | 秃鹫打头，食人花第二 | 秃鹫+战旗 / 食人花 / 虎人+尖刺拳套 / 半精灵人<br>秃鹫+尖刺拳套 / 食人花 / 虎人+战旗 / 半精灵人<br>秃鹫+尖刺拳套 / 食人花 / 虎人 / 半精灵人+战旗 |
| B | 秃鹫+尖刺拳套放第三，食人花在前两位 | 食人花+战旗 / 半精灵人 / 秃鹫+尖刺拳套 / 虎人<br>食人花+战旗 / 虎人 / 秃鹫+尖刺拳套 / 半精灵人<br>虎人+战旗 / 食人花 / 秃鹫+尖刺拳套 / 半精灵人<br>虎人 / 食人花+战旗 / 秃鹫+尖刺拳套 / 半精灵人<br>虎人 / 食人花 / 秃鹫+尖刺拳套 / 半精灵人+战旗 |
| C | 半精灵人、虎人在前，秃鹫+战旗第三，食人花+尖刺拳套殿后 | 半精灵人 / 虎人 / 秃鹫+战旗 / 食人花+尖刺拳套<br>虎人 / 半精灵人 / 秃鹫+战旗 / 食人花+尖刺拳套 |

- 同一组内的差别主要是战旗放在谁身上。集结是全队统计的，所以放在谁身上影响不大。合并后约 3 组，与"去掉对称后 1–4 组"的记忆一致。

## 虎虎生风

- 敌方：虎人+荆棘 / 虎人+光环 / 虎人+木剑 / 虎人+号角
- 玩家可用：盾卫、半精灵人、虎人、虎人；装备 剧毒之牙、狮心。
- **466 种摆法，5 个解，通过率 1.07%**。

| 组 | 思路 | 解 |
|---|---|---|
| A | 虎人+狮心打头，半精灵人+剧毒之牙第二 | 虎人+狮心 / 半精灵人+剧毒之牙 / 盾卫 / 虎人<br>虎人+狮心 / 半精灵人+剧毒之牙 / 虎人 / 盾卫 |
| B | 虎人+狮心打头，虎人+剧毒之牙第二 | 虎人+狮心 / 虎人+剧毒之牙 / 盾卫 / 半精灵人<br>虎人+狮心 / 虎人+剧毒之牙 / 半精灵人 / 盾卫 |
| C | 盾卫+剧毒之牙第三 | 虎人 / 虎人+狮心 / 盾卫+剧毒之牙 / 半精灵人 |

合并后同样约 3 组。

## 备注

- 两关的通过率都在 1% 左右，解的结构清晰（约 3 组），符合"高难度解谜"的定位。
- 以后改规则或数值时，用 `just levels` 复核。解的数量变化很大时，再讨论是否调关卡。
