# 关卡

> 活文档：现有关卡的数据与解。解由 `just levels` 枚举得出，规则改动后重新枚举。
>
> **枚举口径**：
> - 玩家的所有摆法都算，包括只上部分角色、装备可以不用；相同的卡互换算同一种摆法。
> - 玩家是 P2。只有获胜算通过，平局不算。

**两关都待重做。** 数值校正的结果写进正式数据之后（issue #36），两关用到的卡大多改了数值：猪突猛进没有解了，虎虎生风的解从 5 个变成 77 个。关卡数据这次没改，之后重新设计（路线图阶段 4）。下面是现在的枚举结果。

## 猪突猛进（待重做：无解）

- 敌方：豪猪+毒囊 / 豪猪+剧毒之牙 / 豪猪+防爆头盔 / 豪猪+铁剑
  - 毒囊、铁剑不带特殊技能，所以这两只豪猪保留反噬3；
  - 剧毒之牙（致命）、防爆头盔（坚固4）会替换掉反噬。
- 玩家可用：秃鹫、食人花、半精灵人、虎人；装备 战旗、尖刺拳套。
- **912 种摆法，0 个解。** 全部是敌方胜，最好的摆法（如 食人花 / 虎人+尖刺拳套 / 半精灵人 / 秃鹫+战旗）也剩一只豪猪 13。
- 冒烟用例里没有这一关的解；冒烟流程只检查它能进入、打完不报错。

## 虎虎生风（待重做：太容易）

- 敌方：虎人+荆棘 / 虎人+光环 / 虎人+木剑 / 虎人+号角
- 玩家可用：盾卫、半精灵人、虎人、虎人；装备 剧毒之牙、狮心。
- **466 种摆法，77 个解，通过率 16.52%**（还有 24 种是平局）。原来的 5 个解都还成立；打头的可以是虎人（50 个解）、盾卫（18 个）或半精灵人（9 个），一半以上是剧毒之牙在交战位。全部的解用 `just level-check` 列出。
- 冒烟流程用其中一个解（虎人+狮心 / 半精灵人+剧毒之牙 / 盾卫 / 虎人）检查"赢了才记通关"。
