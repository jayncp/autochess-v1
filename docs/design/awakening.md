# 卡牌觉醒

> 现行规则（第一轮测试后的方案，2026-11-26）。游戏里还没有实现；数值会在实战模拟后再调。
> 每张角色的方案在 `tools/balance/awaken-templates.json`，觉醒后的数值在设计表 `card-workbook.xlsx` 的"觉醒"页（脚本生成）。

## 1. 规则

- **三张相同的角色合成一张觉醒的**，自动合成，不能选择不合。装备没有觉醒。
- 觉醒的牌是同一张牌的强化版：星级、种族、时机不变，卡名后加星号（`密林射手*`）。
- 牌库里一张觉醒的牌按 3 张原卡算；卖出 3 金币。
- 同名的普通牌最多留 2 张（第 3 张就合成了）；觉醒的张数不限，只受牌库张数限制（5★ 每种 6 张，最多两张觉醒）。
- 界面上的表现（合成的落点、动画、卡面）见 [../plans/shop-build-ui.md](../plans/shop-build-ui.md) 第 5 节。

## 2. 觉醒后怎么变强

一张牌有三个维度：**战力、基础技能、特殊技能**。每个维度是不变、×1.5、×2 三档，一张牌的方案写成"战力 ×2 + 基础技能 ×1.5"这样。

| 维度 | 怎么算 |
|---|---|
| 战力 | 战斗力乘倍数，四舍五入（半数进一） |
| 基础技能 | 每个基础技能的数值乘倍数，四舍五入 |
| 特殊技能·带数值的 | 词条的数值（庇护、坚固、反噬）、效果里的数值（+N、获得的数值、神佑的层数）乘倍数，四舍五入 |
| 特殊技能·按次数的 | "多结算一次""多触发一轮""额外获得一份"变成两次、两轮、两份 |
| 特殊技能·按范围的 | "下两位"变成"下四位"，"对方前两位"变成"对方前四位" |

- 按次数、按范围的加强没有 1.5 倍这一档，统一记 ×2。
- 不带数值的词条（致命、协战、免疫致命）和没有数值的效果（唤醒、清除、一半、减半、之和）不变；这类牌靠战力或基础技能觉醒。
- 特殊技能有几个数值时，倍数只表示加强的力度，具体哪个数变以设计表"觉醒"页的文字为准。
- 写死的例外只有一张：千机魔女的装备倍数 3 倍 → 4 倍（记作特殊技能 ×1.5）。

## 3. 怎么给一张牌定方案

- **优先特殊技能**：有特殊机制的牌尽量靠机制觉醒；其次基础技能；实在没有机制的才用战力。
- **标准是一个维度 ×2**。偏强的用一个维度 ×1.5；偏弱的叠两个维度。
- 集结、振奋这类全队收益的基础技能翻倍后太强时，换成战力，或者降到 ×1.5。
- 普通版已经很常用的牌（提供机制的挂件）不必让觉醒版也强，觉醒版带卡得分不太低就行。
- 一张牌只要普通版、觉醒版有一个好用就算合格；两个都没人用的才要注意。
- 每个回合档要有值得觉醒的牌，但不要集中在一两张上（警戒线：一张觉醒牌在一个回合档的出场率超过 40%）。

现在 87 张角色的方案：

| 方案 | 张数 |
|---|---|
| 特殊技能 ×2 | 33 |
| 战力 ×2 + 基础技能 ×2 | 17 |
| 基础技能 ×2 | 15 |
| 战力 ×2 + 特殊技能 ×2 | 7 |
| 基础技能 ×2 + 特殊技能 ×2 | 6 |
| 战力 ×2 | 4 |
| 基础技能 ×1.5（风精灵、六翼天使） | 2 |
| 特殊技能 ×1.5（神官、千机魔女） | 2 |
| 战力 ×1.5（猛犸） | 1 |

## 4. 实现的现状

- 觉醒的牌在结算里是另一张卡（id = 原 id 加 `_awakened`），由 `tools/autochess_tools/awaken.py` 按方案从原卡生成，只用于模拟和搜索，还没有写进 `data/cards.json`。
- **两次 / 两轮 / 两份（`times`）和两个新范围（`next_four`、`enemy_first_four`）现在只有 Rust 版认**，GDScript 版还没有。在游戏里实现觉醒时，要按"改战斗规则"的流程先在 GDScript 版补上，再对拍。
- 测试的方法和结论见 [../plans/gold-search.md](../plans/gold-search.md)，各回合档的出场率见 [gold-report-2026-11-26.html](gold-report-2026-11-26.html)。
