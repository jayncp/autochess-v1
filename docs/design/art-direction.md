# 美术与界面规范

> 活文档：画风、卡面、各界面的布局和控件。实现进度见 [../plans/ui-redesign.md](../plans/ui-redesign.md)。
> 样稿（HTML 和截图）在仓库外的工作区 `design-workspace/mockups/`。和样稿不一致时以本文为准。

## 1. 风格

- **画风**：
  - 日式动画、线条干净的 2D；不要像素、不要太卡通、不要油画质感；
  - 人形角色参照异世界、冒险类动画（如《刀剑神域》）；非人形参照宝可梦式的生物设计，但必须是原创；
  - 主题是魔法、魔幻。
- **标题**："牛马自走棋"是临时名，不要标语。
- **背景**（`assets/backgrounds/`）：同一个世界，黄昏、浮空城；中间区域平静，细节放在四周。

  | 界面 | 背景 |
  |---|---|
  | 主菜单 | 悬崖上远眺浮空城 |
  | 关卡选择 | 冒险者公会的委托告示板 |
  | 构筑阶段、科研模式 | 法师骑士团的作战桌 |
  | 战斗 | 浮空岛上的决斗场 |
  | 图鉴 | 魔法书库 |

- **字体**（都是 OFL，按 GB2312 加翻译表用到的字子集化，见 `just fonts`）：
  - Noto Serif SC 粗体：卡名、标题、按钮、菜单；更重的用加粗（`serif_heavy`），标题再加字间距（`serif_title`）；
  - Noto Sans SC 可变字重：其余文字和数字（`sans` 400、`sans_medium` 500、`sans_bold` 700）。
- **颜色**：

  | 用途 | 颜色 |
  |---|---|
  | 金线、菱形 | `#ffd98a` |
  | 按钮文字 | `#f3e6c4`；主按钮 `#fff3d0` |
  | 面板底 | 深蓝渐变 `#182046` → `#090c1e` |

## 3. 卡牌

### 3.1 卡面

- **布局**：
  - 角色卡：左上星级（竖排），上中卡名，右上种族图标（竖排），左中装备框；下方依次是特殊技能，以及"时机 → 基础技能"区加右侧战斗力；
  - 装备卡：同样的布局，没有种族和装备框。
- 卡名、星级、种族图标直接压在卡图上，加黑色描边，不用矩形框。
- 角色统一朝右，避免被装备框挡脸。
- **种族**：

  | 种族 | 颜色 | 图标 |
  |---|---|---|
  | 人族 | 橙 `#f28c28` | 旗子 |
  | 动物 | 红 `#e5483b` | 爪子 |
  | 神族 | 黄 `#f2c94c` | 一对翅膀加光环 |
  | 精灵 | 青 `#29c4d6` | 蝴蝶翅膀 |
  | 自然 | 绿 `#5dbb46` | 叶子 |
  | 财宝 | 粉 `#f07cc0` | 钱币 |

- **时机**：战前（沙漏，青）、入场（进入门框，绿）、交战（交叉双剑，红）。
- **星级**：1★ 黑铁、2★ 黄铜、3★ 白银、4★ 黄金、5★ 棱彩。星级越高，边框越宽、装饰越多，轮廓也随之变化：

  | 星级 | 边框 |
  |---|---|
  | 黑铁 | 粗糙锤打颗粒，四颗铆钉，纯矩形 |
  | 黄铜 | 氧化斑驳，刻槽，角片加螺栓，侧边小螺栓 |
  | 白银 | 抛光高光，双刻槽，珠饰，卷草角花，四边的菱形凸出卡外 |
  | 黄金 | 金卷草，外凸的扇形角饰嵌蓝宝石，上下冠饰嵌红宝石，侧边徽章，珠饰 |
  | 棱彩 | 彩虹渐变，内缘辉光，四角水晶簇、上下水晶冠、侧边水晶都伸出卡外，卡外有星芒 |

- **背景**：
  - 角色：底色取种族色，多种族时按扇区融合（2–4 种族都适用）；法阵的颜色和复杂度由星级决定；
  - 装备：底色随星级（铁灰、古铜、银蓝、暗金、棱彩），用六边形附魔阵，同样随星级变复杂。
- **面板**：深蓝渐变底，细线颜色随星级，边缘有菱形点缀。
- **装备框**：装备在角色身上时显示图标、名称、星级。
- **特殊技能**：文字。描述型的（队长、蟾蜍这类）写整句。
- **时机和基础技能**：
  - 完整卡：2×2 表格（时机-1/2、基础技能-1/2）；装备卡的表格直接显示它填在哪一格（2 号格叠加、1 号格覆盖、"空"是清空）；
  - 紧凑卡和战斗实时状态：左边竖排这张卡有的时机图标，右边是合并后的基础技能；都按数量居中；
  - 基础技能方块：种族色的浅色版，配黑字（常规字重）；
  - 按内容多少自动缩小字号：实时状态和紧凑卡可以换行，表格每格一行。
- **战斗力**：白字黑描边，始终显示当前值。
- **还没有卡图的卡**：卡图区显示第一种族的大图标（装备是虚线六边形，角色身上的装备框里也是），淡显。
- **卡内字号**（缩放 1 时）：卡名 30px，特殊技能 21px，基础技能方块 20px，时机文字 19px，战斗力 46px，装备名 18px。

### 3.2 两种形态

| | 完整卡 300×420 | 紧凑卡 300×300 |
|---|---|---|
| 卡图 | 高 | 矮 |
| 时机和基础技能 | 2×2 表格 | 合并后的一行（和战斗实时状态同样的样式） |
| 其余元素 | 同样大小 | 同样大小 |
| 用在 | 图鉴、战斗、手牌、队列（默认）、放得下时的选卡区 | 打开紧凑模式后的队列、放不下完整卡时的选卡区 |

### 3.3 战斗中

- 显示实时状态：时机图标发动时加亮发光；战斗中改变的数值（包括特殊技能，如庇护被消耗）显示紫字和紫色外框。
- **发动者的反馈**：正在结算的基础技能方块亮起（白框、方块色的外发光、放大 1.16）；特殊技能、角色专属效果起作用时（发动唤醒、致命、反噬，受击时庇护、坚固挡伤害，队长、蟾蜍）特殊技能栏亮起（白框加光）。
- **战斗力跳动**：变化时数字放大回弹，带绿光（增）或红光（减），0.45 秒恢复。致命命中后显示 0（不显示很大的负数）。
- **庇护的保护罩**：有庇护（层数大于 0）时卡外一直罩着一圈淡金的光带、亮金边和外发光，多层和单层一样；用完就消失。其他词条不加常驻特效。
- **数值降到 0 的词条移除**：庇护用完后从特殊技能栏去掉，不显示"庇护0"。
- 蟾蜍这类只在结算时生效的加成不改卡面数值，触发时在持有者身上弹卡名。
- 飘字见 5.6。
- 点卡查看（`CardDetail`）：左边是合成后的大卡（1.6 倍，实时状态、当前战斗力），中间一个等号，右边是拆开的角色卡、装备卡（0.75 倍，原始状态）；没带装备时右边只有"原始卡面"。点任意处关闭。

### 3.4 实现

- 卡牌根节点 `card.tscn`（`Node2D`）管拖放、悬停和动画；卡面是子节点 `face`（`CardFace`，`scenes/components/card/card_face.gd`），原点在卡牌中心。
- 卡面全部在 `_draw` 里画，一张卡只有三个节点（卡面、背景、光晕）。布局按缩放 1 写，乘以 `display_scale`；文字按显示字号栅格化，缩小显示时也清楚。背景渐变是着色器 `card_background.gdshader`。
- 接口：`show_cards(角色 id, 装备 id)`；`compact`、`display_scale`；`glow`（拖动、出列时的金光）、`shadow`（叠压的手牌）、`engaged`（交战位的红框）；战斗中 `start_live(开战时的单位属性)`，之后 `set_strength`、`set_specials`、`set_firing(时机)`，点卡查看用 `copy_live` 复制实时状态。
- 卡面以外也要画卡面元素的地方（关卡头像、图鉴的筛选和词条说明）用它的静态函数：`apply_background`、`draw_chip`、`draw_placeholder`；在 `_draw` 里画的纹理都用 `cached_texture` 取（绘制命令只记纹理的 RID，没人持有的纹理会被释放）。
- 卡面贴图和卡图导入时生成 mipmap（项目的导入默认值），缩小显示时不起锯齿。

### 3.5 卡图

- 透明底，只画角色本体，统一朝右。
- 装备和来源角色对应（[card-design.md 第 4 节](card-design.md)）：先画角色，再画它的武器、身体部位或战利品。
- 星级越高，设计越复杂：服饰、装饰、特效、体型逐级加码。

## 4. 紧凑模式

构筑阶段和科研模式右列的开关。打开后，**队列换成紧凑卡，腾出的高度给"选卡"的那一排**。

| | 构筑阶段（闯关，以后的冒险） | 科研模式 |
|---|---|---|
| 关闭 | 对方一排是缩小的完整卡（0.6 起），我方一排和手牌是完整卡 | 双方队列是完整卡，选卡区按剩下的高度用紧凑卡或完整卡 |
| 打开 | 双方队列都是紧凑卡；手牌放大成完整卡 | 双方队列都是紧凑卡；选卡区放大成完整卡 |
| 拖动 | 从手牌拖到队列上方时，卡牌变成队列的样式 | 同左 |

默认值在设置里（默认关闭），每次进入构筑阶段、科研模式时读；进入后可以临时切换，打完一场回来保持刚才的状态（`global_var.compact_mode`）。

## 5. 界面

### 5.1 尺寸

- **画布**：高固定 1080，宽随屏幕（拉伸方式 `canvas_items` + `expand`）：手机约 2376，16:9 的 PC 是 1920；比 16:9 更方的屏幕高度会变大。各界面都按画布大小布局，卡牌缩放按可用宽度和高度计算，取较小的一个。
- **更高的屏幕**（16:10、4:3 这类，以及 16:9 下的空余）：多出来的高度给"选卡"的那一排——构筑阶段给手牌（再给对方一排），科研模式给选卡区，卡牌最大到缩放 1；还有剩余就整体上下居中。战斗两排之间最多空 420，再多就两排向中间靠拢。主菜单的标题和菜单项上下居中。
- **字号标准**：以手机实机截图（2376×1080）为参照，卡牌描述约 20px、卡名约 27px、按钮约 25px、说明面板正文约 29px。场上卡牌的技能文字不小于约 18px；PC 屏幕近、能悬停，可以小一些。
- **触控**：按钮高至少 54px，主要按钮 66–84px。

### 5.2 主菜单

左侧标题，下面是竖排的菜单项，最后一项是"设置"；冒险、线下对战灰显并标"未开放"。启动时读存档出了问题（用备份恢复、进度重置、存档来自更新版本），弹一次通知对话框（见 [save-data.md](save-data.md)）。

### 5.3 关卡选择

- 标签页分教学关、解谜关（教学关还没有，显示"即将开放"）。
- 一行三个关卡，每个只有编号、关卡名和展开箭头；关卡多时上下滚动；关卡名太长时省略号截断。
- 已通关（存档里的通关记录，赢了才算）：绿色边框，右上角一个绿色对号，不写文字。不做解锁。
- 点关卡直接进入；点右边的圆形箭头按钮展开详情（同时只展开一个），再点收起。详情横跨整行，插在这一行下面，用小箭头指向所选关卡；内容是敌方阵容和"进入关卡"按钮。
- 敌方阵容：角色是大圆头像，装备是小圆，完整压在左下角（和卡面上装备框的位置一致），右上角标位置号，下面写角色名；放不下时可以左右拖动，这时右边渐隐并显示滚动条。头像的底色和圈的颜色和卡面一致（`UnitPortrait`）。
- 列表放在背景图的告示板上：背景按宽度铺满、顶端对齐，列表的位置按背景的缩放算，最宽 1700。

### 5.4 构筑阶段（闯关布阵）

- 上面一排是对方，中间一排是我方，底部一整行是手牌；交战位在最左，用红色双剑标出。左列是竖排的阵营旗帜（对方红、我方蓝），字在旗子里居中。
- 不设顶栏：返回是左上角的图标按钮；关卡名在右列，和对方一排对齐；上场计数、"开始战斗"、紧凑模式开关、"整理手牌"在右列，和我方一排对齐。
- **整理手牌**：按图鉴的默认顺序（卡牌序号：角色在前，装备在后）重新排手牌；合并过的卡按角色算。
- **卡位上限**：最多 7 个，关卡或局外等级可以限制。可用的卡位是金色虚线框加位置号，超出上限的显示锁和"未解锁"；右列显示"上场 3 / 5"。
- **手牌**：不加托盘；张数不设上限，放不下时依次叠压，右边的压住左边的。
- **拖动**：卡牌抬起并发光，原位置留下半透明的影子，目标卡位高亮。按下后几乎没动就松开算"点一下"，卡牌回原处。
- **看卡**：PC 悬停、手机长按，在卡的上方显示放大的卡（被查看的卡的 1.3 倍，在 1.15 到 1.3 之间），水平对着这张卡；上方放不下的（队列里的卡）从这张卡的下边往上展开，盖住它自己。从不放在下方和左右，不挡手牌、选卡区和同一排的卡。拖动时不显示。项目开了"鼠标模拟触摸"，PC 上也会报告有触屏，所以按平台（`mobile`）判断用悬停还是长按。
- **布局**：对方一排、我方一排、手牌三行上下居中；我方一排的缩放取"7 列放得下宽度"和"三行放得下高度"中较小的（1920 宽约 0.65，2376 宽约 0.87）；多出来的高度先给手牌（最大 1），再给对方一排（从 0.6 起，最大和我方一样大）。右列和我方一排居中对齐，紧凑模式下这一排比右列矮，手牌往下让到右列下面，不压住"整理手牌"。
- 至少上场一个角色才能开始战斗，否则弹通知对话框。

### 5.5 科研模式

- 和构筑阶段同一套布局，阵营同样是对方、我方，只是对方也可以编辑；没有上场上限。
- 点卡位选中（金色光圈），下面的选卡区就为它选卡：标签页分角色、装备，可以按星级、种族筛选，也可以搜索；选卡区横向滚动（横着拖）。
- 选中有卡的卡位时，选卡区右上角可以"移除"或"卸下装备"；也可以直接把卡从选卡区往上拖到任意卡位（不留影子，原卡还在选卡区），或把场上的卡拖出去。选中的卡位还没有角色时，装备页的卡变暗、不能选。
- 选卡区的卡填满剩下的高度（最大 1）：完整卡至少和队列一样大时用完整卡，否则用紧凑卡。紧凑模式下队列变矮，选卡区的卡跟着变大。星级筛选"全部星级"会去掉其他星级的勾选。
- 右列：标题、"开始战斗"、"交换双方"、"清空全部"（弹确认对话框）、紧凑模式开关。

### 5.6 战斗

- 上面一排是对方，下面一排是我方，卡牌占满宽度（最大缩放 0.93：1920 宽约 0.79，2376 宽 0.93），离上下边各 22；战斗中不显示空位。
- 中间一带：左边是交战位标记；页面正中是状态（开战前是"开始战斗"按钮；战斗中是阶段名（时机图标加名称，时机色的光），下面一行战前是"第 k 步"，之后是"第 N 次交战 · 无人阵亡 x / 20"；结束后是"胜利/失败/平局"、原因加"返回"）；右边是速度（1×、2×、5×、20×，开战时是设置里的默认速度）和跳过。
- 胜负按我方（下面一排）说；原因：对方全部阵亡 · 我方幸存 N 人、我方全部阵亡 · 对方幸存 N 人、双方同时全部阵亡、连续 20 次交战无人阵亡。
- 交战位的卡有红色外框。卡的位移按两排之间的空隙算：轮到时向中间靠 6%，发动时到 15% 并放大到 1.04、金光，交战冲到 30%。
- 点卡查看：见 3.3；战斗照常进行。
- **飘字**（`FloatBadge`，`scenes/battle/fx/`；规格和样稿见 [plans/effects-pacing.md](../plans/effects-pacing.md) 第 3 节）：
  - 四类：
    - 基础技能：技能色的名称加带纹样的饰板，每个技能的纹样不同；
    - 词条：银边饰板，左边圆章里是种族色的图标，白字；
    - 角色专属效果：白色宋体卡名；
    - 交战伤害：只有数字，比其他飘字大一号。
  - 数值只表示战斗力实际的变化：加绿、减红，财富金色，层数白色。伤害被庇护挡下、被坚固挡完时只弹词条；坚固减了一部分时先弹坚固，0.15 秒后再弹实际扣的数值。致命命中是"−∞"。
  - 压在卡图中间、跟着卡移动，停留 1.1 秒（弹出、上浮、最后 0.3 秒淡出）；同一张卡上后弹出的在原位，先弹出的往上推一格。变速时飘字跟着加快，但至少停 0.45 秒。
  - 角色专属效果（描述型特殊技能）有通用方案：持有者特殊技能栏亮起、弹卡名，改了自己的战斗力就带数值；要单独设计时在 `battle_manager` 里写 `_fx_<效果 id>` 方法覆盖。
- **节奏和动作**（`battle_manager` 的 `PACE`，时长见 [plans/effects-pacing.md](../plans/effects-pacing.md) 第 4 节）：
  - **一步**：轮到 → 发动 → 一拍一拍 → 交战 → 反噬 → 收回。
    - 战前的每一步，这一步的双方单位亮青色光圈，标出进行到哪里；
    - 每一拍：发动者的方块先亮，再飞向作用对象，生效后留 0.5 秒看，一拍约 0.85 秒。
  - **从发动者到作用对象**：
    - 支援、振奋是光球（振奋每个队友一颗，远的晚到）；
    - 腐蚀是毒液弹，命中时溅开；
    - 湮灭是紫色光球；
    - 狂暴是卡图上的爪痕，财富是弹起的金币；
    - 集结时，带集结值的队友飞来一串光点；
    - 唤醒是一道青色的光；
    - 队长、蟾蜍是白线。
  - **受击**：
    - 卡面泛红、左右抖一下；
    - 庇护还有层数时保护罩亮一圈，用完时碎开；
    - 坚固是一道金属光；
    - 反噬炸开一圈尖刺。
  - **交战**：后撤蓄力 → 加速冲向中间 → 撞上（冲击光、画面震动，只震卡牌和特效、不震按钮）→ 停顿 → 弹回。
  - **阵亡**：卡牌临时套一个 `CanvasGroup`（着色器 `scenes/battle/fx/dissolve.gdshader`），先变灰，再按噪声烧散，烧口有一圈橙色的边，余烬上飘；烧到七成时后面的卡补位（略带回弹）。
  - **变速**：1×、2× 完整演出；5× 不飞光球、不连线；20× 也不弹飘字、不加特效。
  - 特效在 `FxLayer`（`fx_layer.gd`）里生成，每个特效是一个 `FxEffect`（`fx_effect.gd`），按进度重画、跟着卡移动，播完自己删掉。

### 5.7 图鉴

- 左侧筛选栏，从上到下：搜索（卡名、种族、词条、效果文字）、类型、星级（1–4★）、种族、时机、基础技能；特殊技能用可多选的下拉（列表弹在按钮上方），只列词条（反噬、坚固、唤醒、庇护、致命），角色专属的描述型效果不列，靠搜索找。基础技能和特殊技能只列有卡用到的。
- 组内是"满足任一"，组间是"同时满足"；类型默认两种都勾上，其他组不勾表示不限。
- 右侧卡牌网格，上下滚动；顶部显示张数、已选条件（可以点 × 去掉）、排序（序号；星级从低到高；战斗力从高到低）、重置筛选。
- 宽度：画布宽 2200 以上时，侧栏 520、网格 6 列，否则侧栏 470、5 列；卡牌缩放按网格宽度算（1920 宽约 0.84，2376 宽约 0.91）。
- 点卡放大（1.7 倍），旁边列出这张卡用到的时机（包括带时机的特殊技能的时机）、基础技能、特殊技能的说明，最后一行是种族、星级、序号；描述型特殊技能卡面上已经是整句，不重复；点任意处关闭。

### 5.8 设置

- 背景用主菜单的，压暗。左上角返回和标题"设置"，和其他界面一样。
- 内容是居中的一列（最宽 1160），上下居中：分组标题（宋体淡金色，后面一条渐隐的金线），下面一个面板；面板里一项一行，左边名称（宋体）和一行说明，右边控件，行之间细线隔开。

  | 分组 | 项 | 控件 |
  |---|---|---|
  | 战斗 | 默认速度 | 1×、2×、5×、20× 四个单选块 |
  | 布阵 | 紧凑模式 | 开关 |
  | 存档 | 存档位置 | 只读的路径框（可以选中）；PC 上右边是"复制路径"（点了短暂显示"已复制"）、"打开文件夹"，手机上没有按钮，说明改成"存档在应用内部，卸载游戏会一起删除" |
