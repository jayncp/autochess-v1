# 卡牌数值设计

> 活文档：数值建模方法和平衡的验收标准，供设计新卡和调平衡时使用。
> 设计理念和平衡原则见 [game-design.md](game-design.md)；模拟验证见各份 balance-report（带时效的快照）。

## 1. 星级和平衡的验收

星级就是成本：玩家陆续解锁卡位和更高星的卡，一套阵容的总星数有上限。所以不给每个星级定一个强度目标，而是比"同样花这些星，谁更值"。

验收看分阶段的阵容搜索（`just balance run`，方法见 [plans/balance-tuning.md](../plans/balance-tuning.md)，读法和经验见 [balance-notes.md](balance-notes.md)）。两条标准，下面的数字是警戒线，越线了要去看原因，不是硬指标：

- **没有废卡**：每张卡至少在一个阶段带卡得分不低于 0.47（用 `just balance check` 复核之后的数，常规搜索会把没人用的卡低估很多）。最高出场率不到 2% 的卡列出来逐张看。
- **没有一家独大**：每个阶段均衡里的阵容按权重折算不少于 30 套，权重最大的一套不超过 6%。士兵、荆棘这类 1★ 的通用填充不算在内。
- 两次搜索之间单张卡的出场率会浮动 4 个点左右，贴着线的不用管。
- 理想的卡是某些阶段强、某些阶段弱，不追求出场率一样。两条满足之后不死磕数值，进实战看。

每张卡各阶段的出场率在设计表（`card-workbook.xlsx`）里，是最近一次定版搜索的快照。

设计新卡时，先找同星级、同类型的现有卡，照它们的数值和出场率定初值，再跑搜索校正。

## 2. 数值建模方法

1. **1★ 锚点**：老虎、士兵、淤泥怪，各代表狂暴、集结、腐蚀；之后按同一数值规模加入天使、小精灵。
2. **2★ 锚点**：虎人、精灵虎、树精这类效果直接的卡。其他 2★ 卡按"实际战力"折算填写，再用模拟对战校准。
3. **同星级下，技能数值大致是 振奋 < 集结 < 狂暴 < 腐蚀**：
   - 振奋、集结作用于群体，单点数值最低；
   - 狂暴大多绑定"交战"、每次交战都触发，数值居中；
   - 腐蚀通常单次触发、立即生效，数值最高。
4. **时机也计入价值**：同一技能放在战前、入场、交战，价值不同。例如精灵虎是战前狂暴10（一次性），老虎是交战狂暴3（每次交战）。
5. **承认装备与角色有适配性**：某些组合会明显变强，这是游戏的魅力之一，不追求消除。
6. **最后按阶段搜索的结果微调**技能数值或身材（基础战力），见第 1 节。

现有数据对"振奋 < 集结 < 狂暴 < 腐蚀"的体现：

| 档位 | 振奋 | 集结 | 狂暴 | 腐蚀 |
|---|---|---|---|---|
| 1★ 角色 | 天使 1（入场） | 士兵 2（入场） | 老虎 3（交战） | 淤泥怪 3（入场） |
| 2★ 角色 | 仙女 3（战前） | 半精灵人 2（战前） | 精灵虎 10（战前） | 树精 5（战前） |
| 1★ 装备 | 光环 1 | 号角 1 | 狮心 3 | 荆棘 2 |
| 2★ 装备 | 圣水 2（另加 2 战斗力） | 战旗 3 | — | 毒囊 5 |

数值校正之后不再严格是这个顺序（比如树精的腐蚀从 10 降到了 5，战斗力从 5 加到了 8），上表只是现在的数。

## 3. 装备设计原则

- 装备来自某个角色：它的**武器、身体的一部分或战利品**。物品和画风与来源角色统一，**机制上与来源角色的能力相关**。
- 不是一一对应：一个角色可以对应多件装备，也有装备没有来源角色。
- 出图时先生成来源角色，再生成它的装备。
- 1★/2★ 的对应关系：

| 来源角色 | 装备 |
|---|---|
| 老虎 | 狮心 |
| 士兵 | 号角、木剑 |
| 灵蝶 | 蝶翼 |
| 天使 | 光环 |
| 淤泥怪 | 荆棘 |
| 仙女 | 圣水 |
| 豪猪 | 尖刺拳套 |
| 盾卫 | 防爆头盔 |
| 光灵 | 闪光球 |
| 圣骑士 | 圣盾 |
| 食人花 | 剧毒之牙 |
| 队长 | 战旗、铁剑 |
| 蟾蜍 | 毒囊 |

- 没有来源角色：戒指、项链、四叶草、空心。
- 3★/4★/5★ 装备的来源角色见设计表的"装备"表。
- **覆盖型装备**：填在基础技能-1，装备后覆盖角色原有的基础技能，数值可以给得高一些（空心、项链、噬心药剂）。没有基础技能的宿主上没有代价。
- **时机类装备**：只给时机，对没有基础技能的宿主无效（踏尘靴换成战前，精灵头纱加一个战前，金色蛇首三个时机全加）。
- 资源库里还有几张只有图的装备，以后可能补做：
  - 小精灵 → 竖笛
  - 精灵虎 → 森灵头带
  - 半精灵人 → 穿云弓
  - 树精 → 藤鞭
  - 秃鹫 → 腐蚀之爪
  - 虎人 → 双节棍
