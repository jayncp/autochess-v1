# 战斗规则

> 活文档：战斗核心的规则规范，测试和实现以此为准。
> 实现在 `scripts/core/battle_sim.gd`（结算）和 `scripts/core/card_db.gd`（装备合并、显示顺序）；战斗场景按 BattleSim 的事件日志回放。
> 标 **[待实现]** 的是已经决定、还没实现的，汇总在第 9 节。

一页版：

- 只有一个数值"战斗力"，既是攻击也是生命。双方各排一列，只有第 1 位（交战位）互相攻击。
- 战斗是确定性的：战前阶段 → 反复"入场、交战"直到一方全灭。
- 每个时间节点里：**特殊技能（记 → 增 → 删 → 改 → 加 → 减 → 醒）→ 基础技能（被唤醒的 → 原本的）**，双方同时，中途不判死。
- 基础技能按拍：狂暴 → 集结 → 支援 → 振奋 → 腐蚀 → 湮灭 → 财富。
- 伤害先过庇护，再过坚固，再看有没有减半，最后扣战斗力。

## 1. 术语

| 术语 | 定义 |
|---|---|
| 战斗力 | 唯一数值，既是攻击也是生命 |
| 角色 | 战斗中的一张卡，可以带一件装备。卡面只用"角色"，文档里的"单位"同义 |
| 队列 | 一方的全部角色，从前往后排成一列，最多 7 个：己方队列 / 对方队列。同名卡可以重复上场 |
| 位置 | 队列里从前往后数第几位；前面有人阵亡，后面的依次前移 |
| 交战位 | 第 1 位的专称；说"第 1 位""前两位"时都包含交战位。只有双方交战位互相攻击，存活的一方留在交战位，伤害不会恢复 |
| 下一位 / 下两位 | 紧挨在后面的一个 / 两个己方角色；后面不够时有几个算几个 |
| 前一位 | 紧挨在前面的己方角色，按当时的队列算；自己在交战位时没有 |
| 全体 | 某一方队列里的所有角色，含自己 |
| 己方角色 / 己方其他角色 | 前者含自己，后者不含 |
| 己方 / 对方 | 相对卡牌的持有者，不用"我方""敌方" |
| 阵亡 | 判死时战斗力 ≤0，被移出队列 |
| 战斗力 +N | 增益，不受坚固、庇护影响 |
| 受到 N 点伤害 | 走伤害流程（第 5 节） |
| 时机 | 基础技能什么时候触发：战前、入场、交战（3.1） |
| 基础技能 | 带数值，在时机触发（6.1）。X值指技能后面的 N，如集结值、腐蚀值 |
| 特殊技能 | 不带时机的是被动，带时机的在那个时间节点先于基础技能生效（6.2、6.3） |
| 触发 | 角色的基础技能生效一轮 |
| 结算 | 某个技能生效一下 |
| 时间节点 | 战前的一步、一次入场、一次交战，也叫时点 |

## 2. 卡牌和装备

一张卡有这几格，角色和装备都可以填任意格：

| 格子 | 数据字段 | 装备合并 |
|---|---|---|
| 战斗力 | `strength` | 不分格：角色的加上装备的 |
| 时机-1 / -2 | `timing_1` / `timing_2` | 两格取并集，同一个时机出现两次只算一次；每个时机都触发全部基础技能。一格里可以写多个时机 |
| 基础技能-1 / -2 | `skills_1` / `skills_2` | 两格同名数值相加 |
| 特殊技能 | `special_skills` | 只有一格，整体覆盖 |

装备像一张卡**盖在**角色卡上，先逐格处理，再把两格合并：

- 装备那一格是空的：沿用角色的；
- 有内容：覆盖角色的；
- 写着"空"（数据里是 `"clear"`）：把角色那一格清空。

由此得到的规则：

- 通常角色填 1、装备填 2，效果就是叠加；装备填 1 就是覆盖角色那一格。例：狂化血清填时机-2，是加一个交战时机；狂战斧填时机-1，是把宿主的时机换成交战；空心填"基础技能-1：空"。
- 带特殊技能的装备会抹掉角色自带的特殊技能。想同时具备致命和庇护，只能角色自带两者、装备自带两者，或者在战斗中获得。
- 换时机、加时机只影响基础技能。带时机的特殊技能按自己写的时机生效：闪光球（入场：唤醒）装在交战角色身上，也只在入场时唤醒。
- 装备在战斗开始时就合并好了，战斗中不再区分某个技能来自角色还是装备。合并时生效的特殊技能（千机之匣、千机魔女）在合并时把数值乘上倍数，卡面上显示的就是乘过的数（和印的不同，标紫）。
- 没有时机的角色，基础技能不会主动触发，只作为被统计的数值，也可以被唤醒（现在的正式卡都带时机）。
- 数据字段说明见 [data/README.md](../../data/README.md)。

## 3. 战斗流程

### 3.1 阶段

1. **战前阶段**：
   - 第 k 步取双方各自第 k 个存活的角色，不论它有没有战前时机；
   - 其中在战前生效的（战前时机，或者带战前时机的特殊技能）按第 4 节结算；
   - 每一步之后判死，并判断是否一方全灭。战前阶段不判平局。
2. **主循环**：
   1. 判胜负和平局。
   2. **入场**：任一方交战位有还没触发过的入场，就结算双方交战位的入场（第 4 节），判死，回到第 1 步。入场是"第一次成为交战位"，每个角色只有一次。
   3. **交战**：交战位有交战时机的按第 4 节结算，每次交战都触发。
   4. **对撞**：双方交战位的战斗力都大于 0 时，同时受到等于对方战斗力的伤害（致命另算）。有一方 ≤0 就不对撞，视为没有发生对撞，第 5、6 步也跳过。
   5. 结算协战。
   6. 结算反噬。
   7. 判死、补位，回到第 1 步。

### 3.2 判死和胜负

- **判死**只在固定的时候统一进行：每个战前步骤后、每次入场后、每次交战后，一次性移除全部阵亡的角色。
- **中途不判死**：时点里战斗力 ≤0 的角色还在队列里，后面的效果照常作用于它，也照常统计它（比如集结），它自己的效果也照常发动。唯一的例外是交战位有一方 ≤0 时不对撞。
- **胜负**：一方没有角色、另一方还有，则后者胜；双方同时没有，平局。
- **平局**：连续 20 次交战无人阵亡，判平局；有人阵亡（包括入场后判死）则计数清零。这条保证战斗必然结束。
  - 2026-11-02 用 20000 场随机对局验证：把上限放宽到 1000 次交战，被这条判平局的对局仍是平局；有人阵亡的对局里，阵亡前最长连续无人阵亡 4 次交战。
- 冒险、对战模式里平局怎么结算（比如比剩余战斗力），到设计局外规则时再定。
- **结果与座位无关**：交换左右后结果对称，测试对每条用例都做镜像检查。

## 4. 时间节点内的结算

### 4.1 顺序

一个时间节点的一轮，从上到下走，和卡面一致（特殊技能栏在上，基础技能栏在下）。双方每一步都同时进行。

| 步 | 做什么 | 例 |
|---|---|---|
| 0. 出列 | 在这个时点生效的双方角色出列 | |
| 1. 记 | 读取并固定要用到的场面，后面按这份记录算 | 沼泽之王读对方交战位的战斗力，眼镜王蛇比较双方的战斗力 |
| 2. 增 | 给技能、给词条、复制 | 神佑、圣咏者、鹦鹉、牛头人 |
| 3. 删 | 清除技能 | 美杜莎女王 |
| 4. 改 | 改基础技能的数值，只改此刻还有的技能 | 风滚草 |
| 5. 加 | 特殊技能直接加战斗力 | 神裁者 |
| 6. 减 | 特殊技能直接造成伤害，走伤害流程 | 沼泽之王、眼镜王蛇 |
| 7. 醒 | 唤醒 | 光灵 |
| 8. 被唤醒的一组 | 被唤醒的角色出列，按拍结算基础技能 | |
| 9. 原本的一组 | 原本在这个时点触发的角色，按拍结算基础技能 | |

- 第 1–7 步是带这个时机的特殊技能，各属于哪一步见 6.2、6.3。
- 交战时点在所有轮结束后才对撞，然后是协战、反噬、判死（3.1）。
- 以后加新效果，只要定它属于哪一步。
- **被动**（卡面写"……时""……后"的）不占步骤，跟着它等的那件事立刻生效（4.4）。

顺序带来的结果：

- 风滚草（入场腐蚀4；入场：己方全体的腐蚀值 +3）：先 +3，自己这次入场就是腐蚀7。
- 白狼王（交战：自身获得狂暴3）：先获得，这次交战就按加过的狂暴值算；狂暴被清除后，下一次交战重新获得 3。
- "记"在所有效果之前：眼镜王蛇入场时比较的是双方此刻的战斗力，双方这次入场的技能都还没结算。
- 神佑给的庇护在所有伤害之前，这一步获得的就能挡这一步的伤害。不过神佑只给下一位，下一位在同一个时点里不会是交战位，所以挡得到的是打全体的伤害（湮灭），腐蚀、对撞要等以后。
- 增 → 删 → 改：同一步里对方给了技能、己方又清除，结果是被清掉；清掉的技能不会被"改"加回来。被清除的角色在这一步结束时一定没有基础技能。
- 美杜莎女王在交战位时，对方前两位的基础技能在触发前就被清除；对方的唤醒照常发动，但被唤醒的角色已经没有技能。

### 4.2 基础技能按拍结算

每一组基础技能按**拍**结算：狂暴 → 集结 → 支援 → 振奋 → 腐蚀 → 湮灭 → 财富。作用对象由近及远，先加后减，局外收益最后。

- 每一拍里，这一组双方的角色同时结算该技能；这一组都没有该技能的拍直接跳过；
- 同一拍里双方的效果互不影响：增益只作用于己方，伤害只作用于对方；
- "先加后减"只在同一组里保证；跨组以时间先后为准，可能先被扣成负数、再被加回来。这只影响画面，不影响结果（中途不判死）。

**顺序影响什么**：中途不判死，所以纯粹加减战斗力的效果，结果与先后无关。先后只影响：

- 庇护挡下哪一下：先轮次，再组（被唤醒的在原本的之前），组内按拍（先腐蚀后湮灭）；交战时点最后是对撞、协战、反噬；
- 技能的增、删、改和读取场面的效果，所以它们的先后在 4.1 里固定。

### 4.3 多一次和多一轮

多触发只有两种，都不是数值 ×2，每一下分开结算：

- **多一次**（卡面写"多结算一次"）：某类技能（如腐蚀）在一轮里多结算一次。
  - 多出来的次数在同一拍里连续结算，每一下分开过庇护和坚固；
  - 各自算一次"结算"，但整轮只算一次"触发"（4.4）；
  - 多个来源相加：两个"腐蚀多结算一次"就是一轮结算 3 次。
- **多一轮**（卡面写"多触发一轮"）：把这个时点的一轮（4.1 的第 1–9 步，含其中的多一次）完整再走一遍。
  - 带时机的特殊技能也重复，被唤醒的那一组也重走；每一轮重新"记"。
  - 和多一次相乘：腐蚀一轮 3 次，再多一轮就是 6 次。
  - 多个来源相加：两个来源就是一共 3 轮。
  - 双方都有就一起走，只有一方就另一方等着。
  - 范围按卡面：
    - 自身；
    - 己方（全体，含持有者自己）；
    - 开战时位于己方第 1 位的角色（那个角色阵亡后补位的不算；持有者自己在第 1 位时没有效果）；
    - 自身和开战时位于己方第 2 位的角色（持有者自己在第 2 位时只多一轮）；
    - 自身和前一位：前一位按当时的队列算，前面的角色阵亡后换成新的前一位。入场只有交战位在执行，所以"自身和前一位，入场多触发一轮"对前一位只在持有者排第 2 位、前一位正在入场时生效。
- 多一次、多一轮在回放里弹来源卡的名字（7.3）。

### 4.4 触发、结算和被动

卡面上"触发"指角色的一个基础技能生效一轮，"结算"指某个技能生效一下。

- 写"结算……时"的被动（蟾蜍、星辰法师、八咫镜）按每一下算，和那一下一起生效：多一次的每一下都算。
- 写"触发……时"的被动（队长、沼泽触手）按轮算：唤醒、多一轮各带来一次触发；多一次不带来新的触发。
- 写"触发……后"的被动（萨满）也按轮算，等这个角色这一轮的这个技能全部结算完（含多一次）才生效：连续几次结算之间数值不变。
- 被动写"基础技能"（任意基础技能）时，每个基础技能各算各的：一个角色有狂暴和集结，一轮就是两次触发、至少两次结算；后面没有人的支援、只做特效的财富也算。
- 例：己方腐蚀多结算一次时，一轮里腐蚀结算两次、触发一次；再加多一轮，就是结算 4 次、触发 2 次。
- 例：两个腐蚀5 的角色先后触发，己方腐蚀多结算一次，带萨满。第一个 5、5，之后己方腐蚀值 +1；第二个 6、6，之后再 +1。

一个角色的一个技能在一轮里的先后：结算一下（连同"结算时"的被动）→"触发时"的被动 → 多一次的每一下（各带"结算时"的被动）→"触发后"的被动。

被动的通则：

- 持有者在队列中就生效（含战斗力 ≤0、还没判死的），被移出队列即失效；
- 持有者自己触发也算；同名卡各自生效，效果叠加；
- **听对方的被动**（八咫镜：对方角色结算基础技能时，己方全体战斗力 +N）由持有者那一方结算，加给持有者的己方全体。它只加战斗力，同一拍里双方互不影响的规则不变。

## 5. 伤害流程

1. 伤害大于 0 且有庇护：挡下这次伤害，消耗一层庇护，到此为止；
2. 否则减去坚固，最低为 0；
3. 战前时点里，带"战前时点受到的伤害减半"的角色把剩下的伤害减半；
4. 扣除战斗力。

- **庇护**像套在外面的一层盾：任何大于 0 的伤害都会先打掉它，坚固本来能挡掉的伤害也一样。
- 腐蚀、湮灭、协战、反噬、对撞（含致命）、特殊技能造成的伤害都走这个流程，每一下各消耗一层庇护。
- **致命**：对撞时攻击视为无穷大（实现为 10000），可以被庇护挡下。对方免疫致命时按普通对撞算。
- **致命伤害**（眼镜王蛇、淬毒匕首）：特殊技能造成的一次无穷大的伤害，同样可以被庇护挡下（消耗一层）。它没有普通伤害可以退回，所以对免疫致命的角色是 0 点伤害，也不消耗庇护。
- **减半**只在战前时点里生效，不管伤害来自什么（腐蚀、湮灭、特殊技能）；入场、交战时点和对撞、协战、反噬都不减半。例：腐蚀10 打坚固3、带这个效果的角色，10 − 3 = 7，减半是 4；雪域神牛（庇护1）挨两下腐蚀5，第一下被庇护挡下，第二下减半是 3。
- 数值减半的效果一律四舍五入（0.5 进 1）。

## 6. 技能

### 6.1 基础技能

| 技能 | 说明 |
|---|---|
| 狂暴N | 自身战斗力 +N |
| 集结N | 自身战斗力 + 己方全体的集结值之和（没有时机的也算） |
| 支援N | 下一位角色战斗力 +N。自己在最后一位时不生效 |
| 振奋N | 己方全体战斗力 +N |
| 腐蚀N | 对方交战位受到 N 点伤害 |
| 湮灭N | 对方全体各受到 N 点伤害，能一次打掉每个角色的一层庇护。恶魔的技能，目前没有卡 |
| 财富N | 获得 N 金币。现在只有特效（黄色数字），不产生金币，不影响胜负 **[金币待经济系统]** |

- 说明在翻译表里（`keyword_desc.<id>`，时机的说明是 `timing_desc.<id>`），图鉴点卡放大时列出。
- 被特殊技能**转化**来的技能（如振奋转湮灭）并入目标技能，在目标技能那一拍结算，数值和自带的合并；卡面上分开显示，用不同颜色区分。目前没有卡用到。

### 6.2 特殊技能：词条

| 词条 | 说明 |
|---|---|
| 反噬N | 每次交战后，自身受到 N 点伤害。只在实际发生对撞后结算，双方都结算 |
| 坚固N | 每次受到的伤害 −N（最低为 0） |
| 协战 | 己方其他角色交战时，对撞之后，对方交战位受到等于自身战斗力的伤害 |
| 唤醒 | 触发下一位角色的基础技能。带时机，写作"战前：唤醒" |
| 庇护N | 抵挡 N 次伤害，每次消耗一层，先于坚固判定 |
| 神佑N | 下一位角色获得 N 层庇护。带时机，写作"战前：神佑2" |
| 致命 | 对撞时攻击视为无穷大，可被庇护抵挡 |
| 免疫致命 | 对方的致命无效，按普通对撞算 |

**唤醒**：

- 相当于插入一次触发：下一位角色的整组基础技能作为"被唤醒的一组"，在原本的一组之前结算。
- 被唤醒的角色自己的时机照常触发；没有时机的角色也能被唤醒。
- 不连锁：只触发基础技能，不触发下一位的特殊技能。
- 例：光灵（入场：唤醒）在第 1 位，精灵虎（战前狂暴10）在第 2 位。战前精灵虎自己 +10；入场时光灵唤醒精灵虎，再 +10，一共 +20。
- 例：淤泥怪带闪光球（入场腐蚀3；入场：唤醒），后面是蟾蜍，对方是圣骑士（9，庇护1）。入场时被唤醒的蟾蜍先出手，腐蚀 7（6，加蟾蜍自己的 1）被庇护挡下；淤泥怪的腐蚀 4（蟾蜍也给它加 1）打中，圣骑士剩 5。

**协战**：

- 在对撞之后、反噬之前结算；只在实际对撞后生效。
- 持有者自己在交战位时不生效（"其他角色"）。
- 多个协战按位置从前往后：第 2 位、第 3 位……同一位置上双方都有就同时结算；每一下单独走伤害流程。
- 持有者战斗力 ≤0（还没判死）也照常生效，伤害等于它的战斗力；不大于 0 就是 0 点伤害，不消耗庇护。

**神佑**：属于"增"；下一位没有时不生效；层数叠加。

### 6.3 特殊技能：描述型

### 6.4 战斗中技能的变化

- 增、删只针对基础技能和词条，改只针对基础技能的数值；特殊技能里写的数字（如"+40"）不变。
- **获得**：没有的加上，已有的数值相加（庇护叠加层数，反噬相加）。整体覆盖只发生在装备合并时。带千机之匣的角色获得、被加的基础技能数值 ×2。
- **清除**：数值置为 0。**数值降到 0 的词条就移除**（如庇护用完），卡面上不再显示，以后统计词条的效果也不算它。
- **改数值**：只改此刻还有的技能。
- 战斗中的变化只在本场有效。

## 7. 卡面文字

### 7.1 写法

1. 带时机的特殊技能写"时机：效果"，多个时机用顿号：`入场、交战：清除对方前两位的基础技能`。
2. 被动写"己方角色触发 / 结算〈技能〉时（后），效果"。
3. 对象只用：自身、下一位、下两位、前一位、己方全体、己方交战位、对方交战位、对方前两位、对方全体；被动里指触发的那个角色用"该角色"。句子省略对象时指自身。
4. 数值写"战斗力 +N""〈技能〉值 +N""受到 N 点伤害"。伤害统一写"对方……受到 N 点伤害"，不写"对对方造成 N 点伤害"；致命伤害没有点数，写"对其造成致命伤害"。
5. 多一次写"多结算一次"，多一轮写"多触发一轮"。
6. 动词固定：获得（增，复制也是获得）、清除（删）、+N（改）、翻倍或变为 N 倍（合并时）。
7. 不说"在场"：被动默认只在队列中生效，不用写出来。

### 7.2 显示顺序

代码里各只定义一处（`CardDB`），卡面、实时状态、图鉴共用；数据里怎么写都按这个顺序显示。

- **基础技能**就是结算顺序：狂暴 → 集结 → 支援 → 振奋 → 腐蚀 → 湮灭 → 财富。
- **特殊技能**按所属种族，同族里词条在前：反噬 → 坚固 → 协战 → 免疫致命 → 触发时该角色加（队长）→ 唤醒 → 庇护 → 神佑 → 致命 → 触发时自身加（沼泽触手）→ 结算时伤害加（蟾蜍）→ 战前伤害减半；不属于某个种族的描述型效果在最后：触发后改数值 → 结算时自身加 → 对方结算时加 → 多一次 → 多一轮 → 翻倍 → 装备的倍数 → 复制 → 获得 → 清除 → 改数值 → 加战斗力（炼药师、神裁者）→ 造成伤害（沼泽之王、致命伤害）。新词条和新效果的位置在实现时补进来。
- **种族**：动物 → 人族 → 精灵 → 神族 → 自然（基础五族）→ 财宝。扩展种族的编号排在后面，它们的词条可以插在结算顺序中间。
- **时机**：战前 → 入场 → 交战。

### 7.3 分隔符和飘字

- 种族、时机、基础技能之间用"、"，如"动物、人族""战前、交战""狂暴2、集结1"。
- 特殊技能之间用"；"，如"坚固4；致命""战前：唤醒；致命"。
- 分隔符在翻译表里（`ui.card.separator`、`ui.card.special_separator`）。
- 文字放不下时，卡面标签按字数自动缩小字号。
- **飘字**：绿红的数字只表示战斗力实际的变化（"狂暴 +2""腐蚀 −3"）；伤害被庇护、坚固挡完时只弹词条；层数和技能值的变化是白字（神佑给的"庇护 +2"、获得的"集结 +1"、改数值的"腐蚀 +3"）。描述型特殊技能用来源卡的名字：改了战斗力的带数字（"队长 +2"），没改战斗力的只弹名字（蟾蜍的腐蚀加成只弹"蟾蜍"）。来源是提供特殊技能那一格的卡，装备覆盖了特殊技能时就是装备。样式见 [art-direction.md](art-direction.md) 5.6。

## 8. 事件日志

`BattleSim` 结算时记录事件，战斗场景按事件播放，测试用它检查自洽。格式见 `scripts/core/battle_sim.gd` 开头的说明，主要有：

- `start`：双方初始阵容；
- `pre_battle`、`enter`、`engage`：每一步；
- `round`：多一轮，第 2 轮起每轮开始时记一个，带这一轮重走的角色和各自的来源；
- `special`：特殊技能的一步里的一个技能，按 4.1 的步骤依次记录（"记"只读场面，不记事件）。技能的变化各是一种效果：获得（`grant`，神佑也是）、复制（`copy`，带获得之后自己的基础技能）、清除（`clear`）、改数值（`raise`），都带变化后的数值；
- `beat`：一拍里双方的增益和伤害（财富只记数值，不改战斗力），带结算后的战斗力；被动的效果记在它等的那一拍里（队长的增益跟在触发的集结后面，蟾蜍的加成记在那一下腐蚀上，萨满的改数值跟在这个角色最后一下腐蚀后面，八咫镜的增益跟在对方的那一下后面）；被唤醒那一组的拍标 `woken`；多一次多出来的结算，效果上标第几次（`again`）和来源（`again_by`）；
- 伤害都记下造成伤害的角色 `by`：腐蚀、湮灭、协战、特殊技能（沼泽之王）是发动者，对撞是对方交战位，反噬是自己（回放据此让发动者的技能方块亮起）；战前减半生效的伤害带 `halved`，致命伤害打在免疫致命的角色上记 0 点、带 `immune`；
- `clash`、`assist`、`backlash`：对撞、协战（同一位置的双方一个事件，从第 2 位往后）、反噬；
- `death`：阵亡；
- `end`：胜负和原因。

日志带版本号 `BattleSim.VERSION`（现在是 9），规则或格式变化时加一，供以后的重播判断版本。Rust 版结算（`engine/`）有同名的 `VERSION`，测试检查两边相等。
