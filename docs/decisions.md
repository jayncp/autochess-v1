## 战斗规则

| 日期 | 决定 |
|---|---|
| 11-07 | **时点结构**：一个时点（战前一步、入场、交战）从上到下结算：特殊技能（双方同时）→ 被唤醒的一组 → 原本的一组；每组按拍，双方同一拍同时生效，都没有的拍跳过。**时点中途不判死**，时点结束才判死、补位。"先加后减"只在同一组里保证，跨组可能出现负数再加回来（只是画面）。顺序主要决定庇护挡哪一下。动画按这个顺序出列、出字 |
| 11-06 | **结算顺序**：狂暴 → 集结 → 支援 → 振奋 → 腐蚀 → 湮灭 → 财富。作用对象由近及远，先加后减（避免同一步里先被打到 ≤0、又被振奋"复活"的观感），局外收益最后。支援N：下一位角色战斗力 +N |
| 11-02 | **特殊技能**：没有时机的是被动，在队列中（含 ≤0、还没判死的）就生效，被移出队列即失效（如地狱之主）；带时机的先于基础技能触发。作用点：装备合并、时间节点、基础技能触发、基础技能结算和伤害流程；局外另定 |
| 11-01 | **特殊技能**随装备整体替换，不叠加。致命+庇护叠加是天花板级机制 |
| 11-02 | **坚固是特殊技能**，随特殊技能整体替换，一个单位只有一个坚固值。以后如果有机制在特殊技能之外额外给予坚固，再定叠加方式 |
| 11-07 | **庇护**：带层数（现有的都是庇护1），每次伤害消耗一层；伤害流程先庇护、后坚固和免疫（坚固能挡掉的伤害也会消耗庇护，相对以前削弱庇护）；获得庇护在特殊技能阶段最先结算，这一步获得的就能挡这一步的伤害；战斗中获得的叠加层数，装备合并仍整格覆盖 |
| 11-01 | **反噬**：双方都结算；走伤害流程，坚固减免、庇护可挡 |
| 11-01 | **湮灭**：克制庇护是有意设计，只出现在最高星级，以后会增加额外获得庇护的手段 |
| 11-01 | 致命可被庇护挡下；没有时机的技能只作被统计的数值（默认） |
| 11-02 | 转化来的技能并入目标技能那一拍结算、数值合并，卡面分开显示、换颜色 |
| 11-07 | **多触发只有两种**：多一次（某类技能或整组基础技能在一轮里多结算一次，同一拍里连续结算；多个相加）和多一轮（针对整个时点，整轮含其中的多一次再走一遍，相乘；被唤醒的一组也重走）。都不是数值 ×2，每一下分开结算。等第一张需要的 3★ 卡再实现，规则见 design/battle-rules.md 3.1 |
| 11-02 | **战斗中获得的词条叠加**，不覆盖；整体替换只发生在装备合并时 |
| 11-10 | **还没判死就照常参与**：战斗力 ≤0、还没判死的角色照常被统计、被作用，自己的效果也照常发动。唯一的例外是交战位有一方 ≤0 时不对撞，视为没有发生对撞，协战、反噬也不结算 |
| 11-10 | **词条的数值降到 0 就移除**（如庇护用完）：卡面上不再显示，以后统计词条个数的效果也不算它 |
| 11-10 | **协战**（人族，待实现）：己方其他角色交战时，对撞之后、反噬之前，对方交战位受到等于自身战斗力的伤害；只在实际对撞后触发；多个协战按位置从前往后扫描（同战前），同一位置双方同时，每一下单独走伤害流程；持有者 ≤0 也照常触发（伤害不大于 0 时为 0，不消耗庇护） |
| 11-10 | **神佑N**（神族，待实现）：带时机的特殊技能（"战前：神佑2"），下一位角色获得 N 层庇护，在特殊技能阶段最先结算 |
| 11-07 | **唤醒**（第一个带时机的特殊技能）：相当于插入一次触发，下一位角色的整组基础技能（含装备给的）作为"被唤醒的一组"，在原本的一组之前结算。被唤醒者自己的时机照常触发；没有时机的也能被唤醒；只触发基础技能，不连锁；时机属于特殊技能本身 |
| 11-06 | **条件触发的特殊技能都叠加**，持有者自己触发也算，同名卡各自生效。队长：己方角色触发集结时，自身战斗力 +2；蟾蜍：己方角色结算腐蚀时，伤害 +2，加完再进伤害流程 |
| 11-10 | **飘字和战斗演出**：基础技能是技能色的纹样饰板加数值，词条是银边饰板加种族色图标，描述型特殊技能用来源卡的白色卡名（来源是提供特殊技能那一格的卡；没有单独设计的效果都用这套通用方案，可以按效果单独覆盖），交战伤害只有数字、大一号。数值只表示战斗力的实际变化（加绿减红），伤害被挡完只弹词条；财富金色，层数白色。节奏、阵亡烧散、庇护保护罩、战前光圈见 plans/effects-pacing.md |
| 11-02 | **平局**：连续 20 次交战无人阵亡；按交战次数计，入场不算。已用 20000 场随机对局验证没有误判（见 plans/stage-2-battle-core.md 执行记录） |
| 11-02 | 冒险、对战模式的平局怎么结算（如比剩余战斗力），到设计局外规则时再定 |
| 11-01 | **羁绊、三合一升星暂不做**；以后服务于冒险、对战这类长程玩法 |
| 11-06 | 龙族的成长N 暂定在局外生效（触发后变为 N+1），特殊技能是构筑阶段进化；亡灵、龙族都只是想法，先做好基础五族 |

### 协议说明

- 诉求：任何人都能免费使用、可以商用；别人基于它做的东西，你也要能用。第二点只有 copyleft（传染性）协议能保证。
- **先紧后松**：你是版权人，以后随时能把新版本改成更宽松的协议。反过来，已经以宽松协议发布的版本就收不回来了。前提是在接受外部贡献之前改，或者让贡献者签 CLA。
- 你**不受自己协议的约束**，可以把自己的作品用在任何项目里，包括闭源商用。
- copyleft 给你的是"按同一协议使用别人的修改"，不是无条件的使用权。
- 纯 AI 生成的图片在部分法域可能不受版权保护；游戏机制和规则本身也不受版权保护。
