## 卡牌与数据

| 日期 | 决定 |
|---|---|
| 11-01 | **卡牌名称和数值以 `data/cards.json` 为准**，中文名以 `i18n/data.csv` 为准；旧表格只作参考 |
| 11-02 | **英文 id** 以 `data/cards.json` 为准；新卡的 id 在各阶段计划里定 |
| 11-06 | **格子模型**：装备像一张卡盖在角色卡上。卡牌有 时机-1/-2、基础技能-1/-2、特殊技能 这几格，角色和装备都能填任意格。合并时先逐格覆盖（有内容覆盖、空着沿用、写"空"清空，数据里写 `"clear"`，`{}` 和省略等价），再把两格合并：时机取并集，基础技能同名相加。通常角色填 1、装备填 2，就是叠加。格子不按"角色/武器"命名。**战斗力不分格**：角色和装备的相加，装备不覆盖角色战斗力。带特殊技能的装备会抹掉角色自带的特殊能力，这是规则的一部分 |
| 11-06 | **术语**：用"基础技能"和"特殊技能"；角色、队列、位置、交战位（第 1 位的专称）、下一位、全体、己方/对方、阵亡的定义见 [design/battle-rules.md](design/battle-rules.md) 第 1 节 |
| 11-06 | **显示顺序**：基础技能按结算顺序；特殊技能按所属种族；种族为 动物、人族、精灵、神族、自然（基础五族），扩展种族编号排在后面（词条结算位置可以在中间），对战模式里作为扩展可选加入。**分隔符**：列表之间用"、"，特殊技能之间用"；"，带时机的特殊技能写"时机：效果" |
| 11-06 | **描述型特殊技能不做成词条**（避免增加玩家记忆负担），卡面写整句、按字数调字号；卡面 UI 以后整体调整 |
| 11-06 | **序号**：4 位，依次是类型、星级、两位流水号；同星级按设计分组和种族顺序排，主要用于图鉴顺序 |

| 11-06 | **经济卡先实现，财富只做特效**（黄色数字，不产生金币）；经济卡不计入平衡均值和抽样环境 |

## 平衡

| 日期 | 决定 |
|---|---|
| 11-02 | **核心理念"大毒盾"**：大克盾、盾克毒、毒克大 |
| 11-02 | 星级平衡原则 |
| 11-23 | **平衡指标只用阶段搜索**（issue #39）：不再给各星级定有效战力的目标均值，有效战力和 1★ 基准矩阵的工具删掉（3★ 以上有效战力和出场率是负相关，照它调会把辅助卡越调越强；1★ 同名卡的三角克制不再作为要求）。验收的警戒线：每张卡至少一个阶段带卡得分 ≥ 0.47（复核后），每个阶段按权重折算 ≥ 30 套、最大单套 ≤ 6%；设计表里列各阶段的出场率，只在定版时用脚本重填 |
| 11-22 | **按对局阶段校正数值**：开局到后期六个阶段，各自限制最高星、卡位、总星数、装备件数，搜索互相克制后的均衡阵容。验收两条：没有废卡（每张卡至少在一个阶段有位置）、没有一家独大（没有一张卡、一套阵容、一个流派占掉大部分环境）。不追求每张卡出场率一样，剩下的留给实战。方法和结果见 [plans/balance-tuning.md](plans/balance-tuning.md) |
| 11-22 | **同名卡的张数**：同名角色 5★ 以下最多 3 张、5★ 最多 2 张（共享牌库里同名牌越拿越少），装备不限。阶段搜索按这个限制 |
| 11-22 | **反制战前的手段放在装备上**（如军团圣盾：战前己方全体获得坚固2），不做直接针对某个时机的角色：装备需要就带，不需要可以换；专门针对的角色在不需要时就是废卡 |
| 11-02 | **角色和装备各自平衡，不按星级互相折算**（装备不占人口，获取方式也不同） |
| 11-02 | 接受 2★ 略强于 2×1★ |
| 11-02 | 同族集中组队的强弱差异来自种族定位不同（人族群体集结、动物一打多、自然机制杀、精灵功能性、神族增益和防守），暂不调整 |

## 战斗规则

| 日期 | 决定 |
|---|---|
| 11-18 | **时点结构**：一个时点（战前一步、入场、交战）的一轮从上到下：特殊技能按 记 → 增 → 删 → 改 → 加 → 减 → 醒，然后是被唤醒的一组、原本的一组；每组按拍，双方每一步同时生效，都没有的拍跳过。被动跟着它等的事件立刻生效。**时点中途不判死**，时点结束才判死、补位。"先加后减"只在同一组里保证。动画按这个顺序出列、出字 |
| 11-06 | **结算顺序**：狂暴 → 集结 → 支援 → 振奋 → 腐蚀 → 湮灭 → 财富。作用对象由近及远，先加后减（避免同一步里先被打到 ≤0、又被振奋"复活"的观感），局外收益最后。支援N：下一位角色战斗力 +N |
| 11-02 | **特殊技能**：没有时机的是被动，在队列中（含 ≤0、还没判死的）就生效，被移出队列即失效；带时机的先于基础技能生效 |
| 11-01 | **特殊技能**随装备整体替换，不叠加。致命+庇护叠加是天花板级机制 |
| 11-02 | **坚固是特殊技能**，随特殊技能整体替换，一个单位只有一个坚固值。以后如果有机制在特殊技能之外额外给予坚固，再定叠加方式 |
| 11-07 | **庇护**：带层数，每次伤害消耗一层；伤害流程先庇护、后坚固（坚固能挡掉的伤害也会消耗庇护）；获得庇护属于特殊技能的"增"，在所有伤害之前，这一步获得的就能挡这一步的伤害；战斗中获得的叠加层数，装备合并仍整格覆盖 |
| 11-01 | **反噬**：双方都结算；走伤害流程，坚固减免、庇护可挡 |
| 11-01 | **湮灭**：克制庇护是有意设计，能一次打掉对方每个角色的一层庇护 |
| 11-01 | 致命可被庇护挡下；没有时机的技能只作被统计的数值（默认） |
| 11-02 | 转化来的技能并入目标技能那一拍结算、数值合并，卡面分开显示、换颜色 |
| 11-17 | **多触发只有两种**：多一次（某类技能在一轮里多结算一次，同一拍里连续结算）和多一轮（整轮含特殊技能、被唤醒的一组、其中的多一次再走一遍）。各自多个来源相加，两种之间相乘；都不是数值 ×2，每一下分开结算。规则见 design/battle-rules.md 4.3 |
| 11-10 | **还没判死就照常参与**：战斗力 ≤0、还没判死的角色照常被统计、被作用，自己的效果也照常发动。唯一的例外是交战位有一方 ≤0 时不对撞，视为没有发生对撞，协战、反噬也不结算 |
| 11-10 | **词条的数值降到 0 就移除**（如庇护用完）：卡面上不再显示，以后统计词条个数的效果也不算它 |
| 11-10 | **协战**（人族）：己方其他角色交战时，对撞之后、反噬之前，对方交战位受到等于自身战斗力的伤害；只在实际对撞后触发；多个协战按位置从前往后扫描（同战前），同一位置双方同时，每一下单独走伤害流程；持有者 ≤0 也照常触发（伤害不大于 0 时为 0，不消耗庇护） |
| 11-10 | **神佑N**（神族）：带时机的特殊技能（"战前：神佑2"），下一位角色获得 N 层庇护，属于"增" |
| 11-07 | **唤醒**（第一个带时机的特殊技能）：相当于插入一次触发，下一位角色的整组基础技能（含装备给的）作为"被唤醒的一组"，在原本的一组之前结算。被唤醒者自己的时机照常触发；没有时机的也能被唤醒；只触发基础技能，不连锁；时机属于特殊技能本身 |
| 11-16 | **触发和结算**：卡面上"触发"指角色的基础技能生效一轮，"结算"指某个技能生效一下。写"触发……时"的效果（队长）按轮算，唤醒、多一轮各算一次，多一次不算；写"结算……时"的效果（蟾蜍）按每一下算 |
| 11-17 | 换时机、加时机的装备只影响基础技能，带时机的特殊技能按自己写的时机生效；同一个时机出现两次只算一次 |
| 11-23 | **千机之匣**：合并装备时自身的战斗力和基础技能数值 ×2，卡面显示翻倍后的数，别的角色统计、复制都按这个数；战斗中获得、被加的基础技能数值也 ×2，获得的战斗力不翻倍。**千机魔女**在合并时把装备给的战斗力和基础技能数值乘上倍数（倍数是参数）。两者都占特殊技能那一格，不会同时生效 |
| 11-18 | **战斗中技能的变化**：获得是没有的加上、已有的数值相加；清除是数值置 0；改数值只改还有的技能；只在本场有效。装备在开战时合并好，战斗中不再区分来源。数值减半四舍五入 |
| 11-23 | **触发、结算的口径**："结算……时"的被动每一下都算，和那一下一起生效；"触发……时"按轮算；"触发……后"（萨满）等这个角色这一轮的这个技能全部结算完才生效，连续几次结算之间数值不变。被动写任意基础技能时，每个技能各算各的 |
| 11-23 | **数值校正带来的规则**（battle-rules.md 4.3、4.4、第 5 节、6.3）：鹦鹉是额外获得一份，不是变成；炼药师加全部；牛头人、白狼王用"自身获得"；致命伤害能被庇护挡、对免疫致命是 0 点；战前伤害减半排在坚固之后；八咫镜听对方的结算，由持有者一方结算；多一轮的范围加"自身和第 2 位""自身和前一位"（前一位按当时的队列） |
| 11-18 | **卡面写法**（battle-rules.md 第 7 节）：带时机的特殊技能写"时机：效果"；被动写"己方角色触发 / 结算〈技能〉时，效果"；对象只用自身、下一位、下两位、前一位、己方全体、己方 / 对方交战位、对方前两位、对方全体，被动里触发的那个角色写"该角色"；多一次写"多结算一次"，多一轮写"多触发一轮"；卡面不说"在场"，伤害统一写"对方……受到 N 点伤害" |
| 11-06 | **被动的特殊技能都叠加**，持有者自己触发也算，同名卡各自生效。队长：己方角色触发集结时，该角色战斗力 +2；蟾蜍：己方角色结算腐蚀时，伤害 +1，加完再进伤害流程 |
| 11-10 | **飘字和战斗演出**：基础技能是技能色的纹样饰板加数值，词条是银边饰板加种族色图标，描述型特殊技能用来源卡的白色卡名（来源是提供特殊技能那一格的卡；没有单独设计的效果都用这套通用方案，可以按效果单独覆盖），交战伤害只有数字、大一号。数值只表示战斗力的实际变化（加绿减红），伤害被挡完只弹词条；财富金色，层数白色。节奏、阵亡烧散、庇护保护罩、战前光圈见 plans/effects-pacing.md |
| 11-23 | **回放的合并显示**：八咫镜这类听对方的被动，对方一拍结算完后合起来显示一次（持有者弹一次卡名和这一拍的总数，己方全体同时更新）；几个来源同时改同一个角色的同一个技能（两个萨满）合成一条白字；战前减半和坚固一样先弹卡名再弹数值。只改回放，不改结算 |
| 11-02 | **平局**：连续 20 次交战无人阵亡；按交战次数计，入场不算。已用 20000 场随机对局验证没有误判（见 plans/stage-2-battle-core.md 执行记录） |
| 11-02 | 冒险、对战模式的平局怎么结算（如比剩余战斗力），到设计局外规则时再定 |
| 11-01 | **羁绊、三合一升星暂不做**；以后服务于冒险、对战这类长程玩法 |
| 11-06 | 龙族的成长N 暂定在局外生效（触发后变为 N+1），特殊技能是构筑阶段进化；亡灵、龙族都只是想法，先做好基础五族 |
