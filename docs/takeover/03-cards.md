## 4. 观察与已确认事项

1. **装备按"来源角色 → 衍生装备"出图**：装备是某个角色的武器、身体部件或战利品，物品与画风统一、机制与来源角色相关（详见 [../design/card-design.md](../design/card-design.md#4-装备设计原则)）。只有图没有数据的 8 张是生图过程文件；其中 6 件装备图以后可能补做成正式装备。
2. **经济类卡（财富/财宝）一张都没进 Godot**，因为还没有商店和金币，等冒险模式。
3. **原 3★ 计划拆成 3★/4★ 两档**并重调数值（完成情况.txt 里的"4星"就是这个打算）；表中 3★ 数值仅供参考。
4. 最新表里有 46 行涂了浅橙色；Godot 已实现和已注释的卡**全部**在橙色行里，未涂色的主要是经济卡、"士气"相关卡和复杂全局效果。推测橙色 = "第一期要做的卡"。
