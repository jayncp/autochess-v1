## 2. 经济/流程备注（G 列，非词条部分）

- `G1`：初始 5☆角色 可重铸任意张1次
- `G2`：初始 5☆装备 选择1个
- `G3`：每次刷新商店2金币
- `G4`：每次战斗胜利给1金币
- `G5`：选秀生命值倒序<br>同生命按序号小有限
- `G6`：选秀数量为玩家数量加2
- `G7`：拍卖底价为1金币
- `G8`：拍卖从序号最大开始降序出价<br>每次至少加1金币
- `G9`：战斗结束后<br>每有10金币，获得1金币
- `G22`：角色价格  3/6/12
- `G23`：装备价格  5/10/20

> `G5` 原文"同生命按序号小有限"，疑为"序号小**优先**"的笔误。
