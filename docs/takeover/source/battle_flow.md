## 回合与队列（原文第 1–6 段）

回合流程：战斗→商店→选秀/拍卖→战斗

每位玩家都有一个队列,最多7个角色

先决定自己的角色与装备顺序
然后通过抽签决定本回合的对手

## 战斗流程

战斗流程：

1.双方依次触发战前效果
2.第1个角色进入交战位，如下图
并触发入场效果，若阵亡，
第2个角色进入交战位并触发其入场效果

```
[图：队列示意]
┌────┬──────────────────────────────────────┐
│红色│              （蓝色）队列             │
│交战│                                      │
│ 位 │                                      │
└────┴──────────────────────────────────────┘
```

3.触发交战效果
4.若均未阵亡，重复3直至有角色阵亡
 下1位角色进入交战位重复2

ps：只有交战位的角色会互相攻击

## 例

例：
p1队列：半精灵人（战力9，战前，集结2），士兵（战力3，入场，集结2），士兵
p2队列：树精（战力5，入场，腐蚀10），老虎（战力4，交战，狂暴2），老虎

1. 半精灵人触发战前集结，战力+6，战力15
2. 半精灵人与树精进入交战位
   树精触发入场腐蚀10，半精灵人战力5
3. 树精战力5和半精灵人战力5交战，均阵亡

4. 士兵和老虎进入交战位，士兵触发入场集结+4，战力7
5. 士兵战力7与老虎战力4交战，老虎触发交战效果狂暴2，战力6
6. 老虎阵亡，士兵战力1

7. 老虎进入交战位
8. 士兵战力1与老虎战力4交战，老虎触发交战效果狂暴2，战力6
9. 士兵阵亡，老虎战力5

10. 士兵进入交战位，士兵触发入场集结+2，战力5
11. 士兵战力5与老虎战力5交战，老虎触发交战效果狂暴2，战力7
12. 士兵阵亡，老虎战力2
13. P1无剩余角色，p2获胜
