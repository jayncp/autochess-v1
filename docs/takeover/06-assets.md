## 2. 卡图流水线（2025-04-07 → 04-13 完成 36 张）

| 阶段 | 规格 | 说明 |
|---|---|---|
| ① ChatGPT 生图 | 1024×1024（剧毒匕首 1024×1536、森灵头带 1536×1024） | 带 C2PA 元数据。首批 10 张透明背景没生效（白底） |
| ② PS 抠图 | 1024×1024 RGBA PSD | 透明图基本只是放进方画布；白底的 10 张手工抠；盾卫原图里被画了"盾卫"两字，已抹掉；老虎保留了地面投影 |
| ③ 导出 | 256×256 **PNG-8 + 1-bit alpha** | 边缘锯齿、半透明（仙女翅膀）变实心、有抖动噪点 |
| ④ 进项目 | 原样复制到 `assets/自走棋卡图/` | 导入：Lossless、无 mipmap、fix_alpha_border |

**prompt 模板**（`完成情况.txt`）：

- 角色：`生成卡牌卡图原画，透明背景，方便抠图；正方形画布，不需要边框和UI，只需要角色本身；二次元动漫画风，卡牌名称为[名称]，[要求]`
- 装备-部分：`将[角色]的[部位]单独取下来作为主体，稍加装饰，……只需要装备本身；二次元动漫画风`
- 装备-掉落物：`击败[角色]掉落[装备]，要求保留原角色部分特征或要素，单独取下来作为主体……`

**画风**：日系二次元 + 西幻 TCG，深色描边、赛璐璐+柔和渐变、暖色高饱和（GPT-4o 偏黄暖调）。首批更偏绘本厚涂，后期更精致，盾卫偏写实——一致性一般。背景是明亮卡通风景；卡面 UI 是炉石风木框+羊皮纸+蓝色珐琅角饰。

## 3. 卡面在 Godot 中的拼装（`scenes/material/card.tscn`）

- 卡牌 180×252（底板 `新卡面UI.png` 1024×1448 缩放），所有文字是叠加的 Label，底图无字。
- 角色图：`card_image` 位于左侧方格，**强制拉伸到 72×72**（不保持宽高比，原图必须正方形）；悬停放大 1.7 倍约 122px。
- 装备图：`equip_image` **强制 30×30**，叠在角色图右上；单独的装备卡也只显示这个 30px 小图 → **装备原画在 30px 下必须轮廓清晰**。
- 战斗中"实时状态"模式用 `新卡面UI-下.png` 盖住底部 2×2 格，显示合并后的时机和技能。
- 卡槽：`石板卡槽.png`（670×1024 → 194×272）。

## 4. 发现的问题

1. 主菜单背景 1536×1024 (3:2) 被拉伸到 1920×1080，横向变形约 18.5%。
2. 背景和卡图都被预先量化成 256 色，大面积渐变有色带风险；卡图 1-bit alpha 边缘粗糙。
3. 卡图缩到 72/30px 且不生成 mipmap，有锯齿/闪烁。
4. 文件名不一致：`尖刺拳套` 在 gpt/psd 阶段写成 `尖刺全套`；`新卡面_UI-下` vs `新卡面UI-下`。
5. 竞技场、公告板的最终 PNG 只在项目里；项目里最终版 `新卡面UI-下.png` 资源库没有。

## 6. 后续 AI 生图建议（codex cli）

1. **prompt**：保留三套模板；去掉"卡牌名称为[名称]"（会诱导模型写字）；补充"1:1、透明背景、不要任何文字/水印、不要地面投影或底座、主体居中约占 85%"；装备加"30px 下剪影清晰、高对比"。每次附 2–3 张已完成卡图作风格参考。
2. **规格**：1024×1024 RGBA 原图；需确认 codex cli 能否指定尺寸/透明背景。白底图用 rembg/BiRefNet 自动抠，PS 只修补；把 alpha=0 区域的 RGB 清零，避免缩放色边。
3. **导出**：在预乘 alpha 下缩放，导出 **RGBA 32 位 PNG**（不再用 PNG-8），尺寸建议 512×512；Godot 导入开启 mipmaps。背景用全色 PNG，让 Godot 负责压缩；主菜单背景按 16:9 重出或裁切。
4. **追溯**：维护一份 manifest（id、英文 id、中文名、prompt、生成日期、各阶段状态、导出 md5）。
