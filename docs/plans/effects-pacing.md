# 战斗特效和回放节奏计划

> **状态**：方案已确认（2026-11-10），下一步开 issue、分 PR 实现，规范随 PR 整理进 [design/art-direction.md](../design/art-direction.md)。协战、神佑的规则和表现都已确定（规则见 [design/battle-rules.md](../design/battle-rules.md) 第 4 节），等有卡用到时一起实现。
> 样稿在仓库外的工作区 `design-workspace/mockups/`：
> - `fx_badges.html` / `fx_badges.png`：飘字一览；
> - `fx_battle.html`：节奏原型，用 Chrome 打开，播放 `BattleSim` 跑出来的真实事件日志，可以播放、暂停、拖动、单步（← →、空格）、变速；最后一场"协战、神佑"是手写的示意日志；
> - `fx_frames/`：原型里的关键帧截图。

## 目标

- 回放时看得清这五件事：**轮到谁 → 谁发动 → 用了哪个技能 → 作用到谁 → 变了多少**。
- 一张卡连发几个技能时，能一拍一拍看清。
- 总时长不变长：省下的是空等和阵亡的时间，不是技能的时间。

**本轮不做**：

- 构筑阶段的拖放、合并、交换反馈；
- 音效；
- 胜负结算的演出。

需要的话另开计划。

## 1. 现状的问题

用 600 场随机 5–7 人对局估算 1 倍速的时长：现在平均 75 秒，P90 是 94 秒。

- **技能太快**：每拍只等 0.3 秒，飘字动画 0.5 秒，一张卡的几个技能会叠在一起。
- **阵亡太慢**：每次阵亡等 3 秒，加起来占总时长的 37%（平均 27.6 秒）。
- **飘字看不出因果**：飘字是纯色文字，看不出是谁发动的。腐蚀、支援、振奋作用到别的卡上时，只在目标身上弹字。
- **发动的卡没有"用哪个技能"的提示**：只是整张卡出列发光。
- **被挡的伤害显示的是挡之前的数**：庇护、坚固挡下后，飘字还是原来的伤害值。
- **致命命中后显示一个很大的负数**：攻击按 10000 算，战斗力 2 的卡被打中后显示 −9998。
- **用完的庇护还显示"庇护0"**。

## 2. 一次技能怎么演

| 阶段 | 发动者 | 作用对象 |
|---|---|---|
| **轮到** | 向中间靠一点（两排空隙的 6%）。战前的每一步，这一步的双方单位亮青色光圈，标出进行到哪里（有阵亡时两边不一定对齐）；入场、交战不加 | — |
| **发动** | 再往前（15%）、放大到 1.04、金光，卡面上的时机图标亮（和现在一样） | — |
| **每一拍** | 卡面上这个技能的方块亮起：白框、放大 | 技能色的光球飞过来，或者在自己身上爆开 → 弹出飘字，战斗力变色跳动，受伤的卡泛红抖动 |

**规则：发动者一定有反应，生效的地方一定有体现。**

- **发动者**：用基础技能时，亮那个技能的方块；用特殊技能或角色专属效果时，亮特殊技能栏。
- **生效的地方**：弹飘字，战斗力变色跳动。
- **两者之间**：用飞行的光球或一道线连起来。

### 2.1 各基础技能

| 技能 | 作用对象 | 从发动者到对象 | 生效 |
|---|---|---|---|
| 狂暴 | 自己 | 不飞，卡图上划过三道爪痕 | 飘字在自己身上 |
| 集结 | 自己 | 己方每个带集结值的角色（含没有时机的）飞一串橙色光点汇过来，表示"汇总全队的集结值"；只有自己有集结值时不飞 | 飘字在自己身上 |
| 支援 | 下一位 | 青色光球，弧线飞过去 | 飘字在下一位身上 |
| 振奋 | 己方全体 | 每个队友一颗金色光球，远的晚一点到（每远一位晚 0.05 秒） | 依次弹飘字 |
| 腐蚀 | 对方交战位 | 毒液弹：抛物线抛过去，沿飞行方向拉长，周围冒泡，身后滴下毒液 | 一圈毒液溅开，液滴落下，冒出绿烟；飘字在对方身上 |
| 湮灭 | 对方全体 | 每个对方角色一颗紫色光球，远的晚到（现在没有卡） | 依次弹飘字 |
| 财富 | 自己 | 几枚金币从卡上弹起 | 飘字在自己身上，数值是金色 |

### 2.2 词条

| 词条 | 发动者（持有者） | 两者之间 | 生效处 |
|---|---|---|---|
| 唤醒 | 特殊技能栏亮，弹"唤醒" | 一道青色的光连到下一位 | 下一位出列、发金光，接着按拍结算它的基础技能 |
| 庇护 | 受击的卡：特殊技能栏亮 | — | 弹"庇护"，不弹数值，层数减一。还有剩余层数：保护罩亮一圈；用完：保护罩碎开，庇护从卡面上移除 |
| 坚固 | 受击的卡：特殊技能栏亮 | — | 卡面上扫过一道金属光，弹"坚固"；减完还有伤害，再弹实际扣的数值（晚 0.15 秒） |
| 致命 | 冲向中间时弹"致命"，特殊技能栏亮 | — | 对方弹 **−∞**，战斗力显示 0。致命的结算方式之后再讨论，表现方向不变 |
| 反噬 | 交战后特殊技能栏亮，卡上炸开一圈尖刺 | — | 弹"反噬 −4" |
| 协战（待实现） | 对撞之后，持有者特殊技能栏亮、向前一顿，身前现出一把光剑，剑尖指向目标 | 光剑加速飞向对方交战位，拖着残影 | 一道斩击，弹"协战 −9"（被挡时同庇护、坚固的规则；伤害为 0 时只弹"协战"）。多个协战按位置从前往后，每个位置晚 0.35 秒，同一位置双方同时 |
| 神佑（待实现） | 特殊技能栏亮，弹"神佑" | 一道金光连到下一位 | 下一位罩上保护罩，弹"庇护 +2"（层数，白字），卡面上的庇护层数增加 |

### 2.3 角色专属效果：通用方案，可以单独覆盖

角色专属效果（描述型特殊技能，如队长、蟾蜍）以后会越来越复杂，表现分两层：

- **通用方案**：没有单独设计的效果都用它。
  - 持有者：特殊技能栏亮，弹白色卡名；自己的战斗力变了就带数值（加绿减红）。
  - 作用在别人身上：从持有者连一道白线（或白色光球）到生效处，那里照常弹飘字。
  - 由别人的动作触发（如己方角色触发集结时）：从触发的那张卡连一道白线到持有者。
- **单独设计**：想做专门的特效时，按效果 id 登记一个表现，覆盖通用方案；不登记就用通用方案。

队长、蟾蜍现在就用通用方案：

- **队长**：特殊技能栏亮，弹"队长 +2"。触发集结的是别的卡时，从那张卡连一道白线过来。
- **蟾蜍**：特殊技能栏亮，弹"蟾蜍"，白线连到被加成的那一下的目标。目标身上的腐蚀飘字直接是加成后的数值（腐蚀 5 + 2 → "腐蚀 −7"），不再挂"蟾蜍"小字：一处可能叠好几个效果，挂上反而乱。

## 3. 飘字

样稿见 `fx_badges.png`。尺寸按卡牌缩放走，和卡面一起变大变小。

### 3.1 四类

| 类别 | 样式 | 例子 |
|---|---|---|
| 基础技能 | 技能色的名称加带纹样的饰板，每个技能的纹样不同；后面是数值 | 腐蚀 −6 |
| 词条（特殊技能） | 统一的银边饰板；左边一枚圆章，里面是词条图标（种族色）；白字。改了战斗力的带数值 | 庇护；反噬 −4 |
| 角色专属效果 | 白色宋体卡名，黑描边、白光，和卡面上的卡名一路 | 队长 +2；蟾蜍 |
| 交战伤害 | 只有数字，比其他飘字大一号（数字 62px，其他 35px） | −12 |

### 3.2 基础技能的纹样

颜色就是卡面上技能方块的颜色，外发光用深一号的颜色。

| 技能 | 纹样 | 颜色 |
|---|---|---|
| 狂暴 | **爪痕**：斜切的饰板，三道爪痕划过两端 | 红 `#ff9d92` |
| 集结 | **燕尾旗**：旗尾形的两端，向内的箭形表示聚拢，边线上一枚菱形铆钉 | 橙 `#ffb66e` |
| 支援 | **蝶翼**：圆头饰板，两端伸出蝴蝶翅膀，带光点 | 青 `#8be8f2` |
| 振奋 | **羽翼与光芒**：尖头饰板，两端展开羽翼，顶上一圈光芒 | 黄 `#ffe07a` |
| 腐蚀 | **荆棘与毒液**：起伏的外形，带刺的藤蔓，底边挂着毒液 | 绿 `#a8e68c` |
| 湮灭 | **碎裂**：两端碎开，碎片飞散，裂纹伸进饰板 | 灰紫 `#d3cede` |
| 财富 | **钱币**：两端是铣边钱币，周围闪光 | 粉 `#fab5dd`，钱币金色 |

### 3.3 词条图标

圆章里的图标用词条所属种族的颜色，顺序和特殊技能的显示顺序一致：

- 反噬：尖刺球（动物红）；
- 坚固：城墙（人族橙）；
- 协战：并排的两把剑（人族橙）；
- 唤醒：睁开的眼睛（精灵青）；
- 庇护：带十字的盾（神族黄）；
- 神佑：光环下的盾，盾上一颗星（神族黄）；
- 致命：滴毒的獠牙（自然绿）。

### 3.4 数值

- **战斗力只显示实际的变化**：加是绿色，减是红色。
- **其他数值**：
  - 财富是金色，因为它是金币、不是战斗力；
  - 层数这类不是战斗力的数值用白色（"庇护 +2"）。
- **伤害被挡**：
  - 庇护挡下：只弹"庇护"，不弹数值；
  - 坚固挡完：只弹"坚固"，不弹数值；
  - 坚固减了一部分：先弹"坚固"，再弹实际扣的数值。
- **致命**：弹"−∞"，卡面上的战斗力显示 0。

### 3.5 位置和停留

- **位置**：压在卡图中间，跟着卡移动。
- **停留 1.1 秒**：先弹出（0.12 秒，略微放大再回弹），中间慢慢上浮，最后 0.3 秒上浮淡出。
- **叠放**：同一张卡上，后弹出的在原位，先弹出的往上推一格（0.1 秒滑上去）。

## 4. 节奏

### 4.1 时长（1 倍速，秒）

原型里的 `PACE` 是同一份数字，可以直接在原型里改了看效果。

| 段落 | 时长 | 说明 |
|---|---|---|
| 轮到 | 0.2 | 战前这一步没人发动：停 0.15 秒就退回，一共约 0.55 秒（现在 1 秒） |
| 发动 | 0.25 + 0.1 | 出列、发光，停一下 |
| **每一拍** | 0.15 + 0.12–0.3 + 0.5 | 方块亮 → 飞行（自己 0.12，支援 0.25，腐蚀 0.3，振奋、湮灭 0.3 起）→ 留 0.5 秒看。有庇护、坚固再加 0.15，约 **0.8–0.95 秒一拍**（现在 0.3） |
| 唤醒、神佑 | 0.3 + 0.2 + 0.1 | 弹词条、连光 → 下一位出列（唤醒）或罩上保护罩（神佑） |
| 交战 | 约 0.95 | 后撤蓄力 0.1 → 冲向中间 0.12（加速）→ 撞上：冲击光、画面震动、弹数值，停顿 0.08 → 弹回 0.25 → 留 0.4 看；致命再加 0.15 |
| 协战 | 约 0.9 | 光剑现出 0.1 → 飞过去 0.3 → 斩击、弹数值 → 留 0.5 看；按位置从前往后，每个位置晚 0.35 |
| 反噬 | 0.6 | |
| 收回 | 0.2 | 发动的卡在交战前先收回 |
| **阵亡** | 约 0.95 | 变灰 0.15 → 烧散 0.5（噪声镂空、橙色燃烧边、余烬上飘）→ 消散到七成时后面的卡开始补位 0.35（略带回弹）→ 新的交战位亮红框（现在 3 秒） |

- **位移**：轮到 6%，发动 15%，交战冲到 30%（两排空隙的比例）。手机上空隙约 255 像素，冲到中间时两张卡还隔约 100 像素，撞击光在正中间。
- **缩放**：轮到时不放大（现在 1.03），只有发动的卡放大到 1.04（现在 1.06）。卡面的字按显示大小栅格化，放大越少越清楚。

### 4.2 总时长

用原型的时间轴代码，在同样 600 场对局上算：

| | 平均 | 中位 | P90 | 最长 |
|---|---|---|---|---|
| 现在 | 75 秒 | 74 秒 | 94 秒 | 111 秒 |
| 新方案 | 49 秒 | 49 秒 | 62 秒 | 79 秒 |

原型的三场演示是 33–48 秒。

### 4.3 变速

- **1×、2×**：完整演出。
- **5×**：不飞光球，直接在目标上生效；飘字至少停 0.45 秒（实际时间），否则看不见。
- **20×**：不弹飘字，只更新战斗力和阵亡，给"快进到结果附近"用。
- 跳过不变。
- 原型里只做了按比例加速，5×、20× 的简化在 Godot 里做。

## 5. 卡面上的反馈（CardFace）

- **技能方块亮起**：`set_firing_skill(技能)`，白框、外发光、放大 1.16；一拍结束熄灭。
- **特殊技能栏亮起**：`set_firing_special(bool)`，白框加光。
- **战斗力跳动**：变化时数字放大回弹，0.45 秒内带绿光或红光。
- **致命命中**：战斗力显示 0。
- **庇护的保护罩**：
  - 战斗中，庇护层数大于 0 的卡一直罩着一层金色保护罩：一圈细金边、边缘淡金光，表面有一道慢慢扫过的光；
  - 多层和单层一样，层数看特殊技能栏；
  - 只在战斗中显示，构筑阶段和图鉴不显示；
  - 其他词条不加常驻特效。
- **数值降到 0 的词条移除**：庇护用完后从特殊技能栏去掉，不再显示"庇护0"。规则上也不再计入，见 [battle-rules.md](../design/battle-rules.md) 第 4 节。
- **战前的青色光圈**：在交战位红框外面再套一圈，两者同时有时都看得见。

## 6. 实现要点

- **事件日志**：
  - 腐蚀、湮灭的伤害效果加上发动者 `by`（现在只能按"同组里对面那个有这个技能的"去推）；
  - `BattleSim.VERSION` 加一；
  - 回放和测试一起改。
- **回放**：
  - `battle_manager` 改成按上面的段落排时间，所有时长和位移放在一张常量表里；
  - 去掉旧的 `buff_text.tscn`。
- **特效节点**（`scenes/battle/fx/`）：
  - 飘字：三段贴图，端饰 48×64、中段拉伸，振奋另有光芒、腐蚀另有水滴；文字在 `_draw` 里按显示字号画；
  - 光球：拖尾的光点；
  - 冲击光、护罩（常驻、受击、碎开、罩上）、金属光、白线和唤醒的光、金币、尖刺、余烬；
  - 腐蚀的毒液弹和溅开、协战的光剑和斩击（拖尾和液滴用粒子）；
  - 用完即删。
- **角色专属效果的表现**：
  - 一张"效果 id → 表现"的表，没登记的走通用方案（第 2.3 节）；
  - 通用方案只需要知道持有者、作用对象、触发者和战斗力变化。
- **阵亡**：卡牌临时套一个 `CanvasGroup`，上烧散着色器（噪声纹理加阈值加燃烧边），余烬用 `CPUParticles2D`。只在阵亡的那一下用，不常驻。
- **素材**：`tools/autochess_tools/art/fx.py` 用和样稿同一份 SVG 生成：
  - 端饰、词条图标、光点、余烬、噪声；
  - 进 `just art`。
- **画面震动**：只震战斗场景的卡牌和特效层，不震按钮。
- **性能**：
  - 一拍最多十几个特效节点；
  - 粒子数量按手机定；
  - 做完在 Android 上实测。
- **测试**：
  - 事件日志的 `by` 字段；
  - 20× 和跳过的冒烟测试：播完不报错，特效节点都被清掉。
- **协战、神佑**：等有卡用到时实现，事件格式先按这个提议（原型的示意日志就是这个格式）：
  - 神佑：`special` 事件，`skill` 是 `bless`，效果 `{kind: "shelter", source, unit, amount}`；
  - 协战：`clash` 之后、`backlash` 之前的 `assist` 事件，效果和对撞的伤害一样，多一个 `by`（持有者），按扫描顺序排列；回放按持有者的位置分组，同一位置的同时演。

## 8. 已确认（2026-11-10）

1. 七个基础技能的纹样、词条的银边饰板、角色专属效果的白色卡名，都按样稿。
2. 生效处不挂"蟾蜍"这类小字：白线已经足够提示，以后一处可能叠好几个效果。
3. 交战伤害显示数字，字比其他飘字大一号。
4. 伤害被挡完时只弹词条，不弹数值；没挡完的显示实际扣的。
5. 节奏按第 4 节，阵亡用烧散。
6. 5× 不飞光球，20× 不弹飘字。

8. 角色专属效果用通用方案，需要时单独覆盖。

    - 对撞 → 协战 → 反噬，中间没有判死；

    - 多个协战按位置从前往后扫描（同战前），同一位置双方同时；
    - 持有者 ≤0、还没判死也照常触发。
14. 神佑是带时机的特殊技能，在特殊技能阶段最先结算。

## 9. 规则一致性检查（2026-11-10）

规则是"没有判死移除之前不算死"。为此检查了结算代码里所有按战斗力 ≤0 做判断的地方：

- **交战位战斗力 ≤0 时不对撞**：唯一的例外，是有意的规则（[battle-rules.md](../design/battle-rules.md) 2.2）。视为没有发生对撞，所以协战、反噬也不结算，和上面的决定一致。
- **伤害大于 0 才消耗庇护**：所以持有者 ≤0 的协战照常触发，但造成 0 点伤害、不消耗庇护。以后如果有"触发协战时"的效果，它算一次触发。
- **其他效果都把 ≤0 的角色当作还在队列里**：
  - 集结汇总的集结值；
  - 支援、振奋、腐蚀的作用对象；
  - 唤醒的下一位，以及它的基础技能照常结算；
  - 队长、蟾蜍、地狱之主这类被动；
  - 反噬（对撞后 ≤0 的一方照样结算）。
  - 没有冲突。

[battle-rules.md](../design/battle-rules.md) 2.1 第 4 条已经补上"它自己的效果也照常发动"和这个例外。
