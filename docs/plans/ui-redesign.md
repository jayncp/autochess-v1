# UI 重做计划

> **状态**：已完成（2026-11-08 至 11-10），issue #14，PR #15–#19。之后的交互特效和节奏另开计划。
> 设计稿和样稿在仓库外的工作区 `design-workspace/`（`README.md` 是现行方案，`mockups/*.png` 是各界面样稿）。规范会随 PR 1 整理进 [design/art-direction.md](../design/art-direction.md)，之后以它为准。

## 目标

玩法、结算、模式结构不变，只重做表现层：卡面、各界面的布局和控件、背景、字体、图标。做到手机上看得清、风格统一。

**本轮不做**：
- 交互特效和战斗节奏：等静态部分在 Godot 里做完，先写规格和用户讨论，再单独做；
- 卡图：概念图只作参考，之后统一绘制（可以和本计划并行）；
- 进度存档（关卡的"已通关"标记先做样式，等存档做了再接上）；
- 音效和音乐。

## 已定的方案（摘要）

详见工作区 `README.md`，PR 1 整理进 `art-direction.md`。

- **画风**：日式动画、线条干净的 2D；人形参照异世界冒险动画，非人形参照宝可梦式的原创生物；主题是魔法、魔幻。
- **卡面**：
  - 卡名、星级、种族图标直接压在卡图上，加黑色描边；装备框在左侧中部；
  - 特殊技能是文字；时机和基础技能在完整卡上是 2×2 表格，在紧凑卡和战斗实时状态里是"时机图标 + 合并后的基础技能"；
  - 战斗力白色，始终显示当前值；战斗中改变的数值显示紫色。
- **种族色和图标**：人族橙/旗子、动物红/爪子、神族黄/翅膀加光环、精灵青/蝴蝶翅膀、自然绿/叶子、财宝粉/钱币。
- **星级边框**：1★ 黑铁、2★ 黄铜、3★ 白银、4★ 黄金、5★ 棱彩，越高越复杂；角色背景色随种族、法阵随星级；装备背景色随星级。
- **两种卡**：完整卡 300×420、紧凑卡 300×300。"紧凑模式"是构筑阶段和科研模式里的开关：队列换成紧凑卡，腾出的高度给选卡的那一排。
- **字号**：以手机实机截图为参照，场上卡牌的技能文字不小于约 18px（1080 高的画布）。
- **屏幕**：画布高 1080，宽随屏幕（`expand`），手机约 2376、PC 1920，卡牌缩放按可用空间计算。
- **去掉战斗的"实时状态"开关**：战斗中始终显示实时状态，点卡查看原始卡面。

## 技术方案

- **卡牌组件**：卡牌根节点仍是 `Node2D`（拖放、射线检测、动画代码都不用改），卡面换成一个自己画的节点 `CardFace`，缩放 0.6 时和旧卡一样大（180×252），所以 PR 2 可以先不动各界面的布局。`load_card` 保留现有接口，改为驱动新卡面。
- **边框、法阵**：Python 生成 SVG，导出成 PNG 放进 `assets/ui/`（Godot 的 SVG 导入不支持滤镜，铁和铜的纹理要先栅格化）。生成脚本放在 `tools/`，只在改设计时重跑。
- **卡图背景**：一个着色器，按种族色（1–4 种）或星级色画渐变。
- **图标**：SVG 放进 `assets/ui/icons/`；放在卡图上的种族图标导出成白色带黑描边的版本，用 `modulate` 上色。
- **字体**：Noto Sans SC、Noto Serif SC 的可变字体，用 fonttools 子集化到 GB2312 字符加常用符号，以控制安装包大小；粗细用 `FontVariation`。子集化脚本放在 `tools/`。翻译表里出现不在子集里的字时，测试报出来。
- **主题**：一个全局 `Theme`（`assets/ui/theme.tres`），场景里不再单独覆盖样式（PR 5 起设为项目主题）。
- **自动缩字**：卡面上的文字按内容逐级缩小字号；基础技能方块、特殊技能的换行由卡面脚本自己排版，不依赖容器的下一帧布局。
- **截图**：加一个无头截图命令，把各界面截到临时目录，方便每个 PR 对照样稿和给用户看。
- **素材清理**：旧卡框、旧卡槽、旧背景在不再使用的那批里删掉。

## 风险

- 字体子集化后，以后新加的卡名或描述可能用到子集外的字：测试检查翻译表的每个字都在子集里，缺了就重新子集化。
- 安装包大小：两种可变字体子集化后预计各 3–6MB，PR 1 实测。
- 卡面的绘制开销：PR 2 改为一张卡只有两个节点，40 张卡同时重画每帧约 0.3ms（M4 Pro）；Android 还没测。

## 执行记录

### PR 1 基础（PR #15，已合并）

- 字体：Noto Sans SC 可变字重（子集 3.9MB）、Noto Serif SC 静态粗体（子集 3.2MB），替换原来 10.5MB 的 Noto Sans SC Regular；字体变体 `sans`、`sans_medium`、`sans_bold`、`serif`、`serif_heavy`。
- 素材生成脚本在 `tools/autochess_tools/art/`（resvg 渲染，支持滤镜），`just fonts`、`just art`、`just theme`；截图 `just shots`。
- 主题只设在重做过的界面的根节点；项目只把默认字体换成 `sans`。全局主题会改坏旧界面（竖排文字的按钮被内边距挤掉），等全部界面重做完再设。
- 主菜单：新背景、金色渐变标题、菜单项；冒险、线下对战不可用并标"未开放"。
- 对话框组件 `Dialog`（通知、确认），PR 3/4 开始用。
- 测试：数据检查加了字体覆盖（翻译表的每个字都要在两种字体里）。

### PR 2 卡牌（PR #16，已合并）

- 卡面 `CardFace`：完整卡、紧凑卡、战斗实时状态；全部在 `_draw` 里画（一张卡两个节点），文字按显示字号栅格化；技能方块和特殊技能按内容缩字、换行；特殊技能逐字上色（战斗中改变的显示紫色）。
- 背景着色器：单种族和 1–4★ 装备是径向渐变，多种族按扇区融合，5★ 装备是彩虹环形渐变；外圈压暗、圆角。
- 所有场景换上新卡，缩放 0.6，布局不变。战斗：开战时进入实时状态；出列的卡时机图标发亮；庇护被消耗显示紫字（用完显示"庇护0"）。去掉"实时状态"开关。
- 还没有卡图的卡：淡显的种族图标（装备是虚线六边形），删掉像素鸟占位图和旧卡框、旧技能底板。
- 卡面贴图和卡图生成 mipmap（项目导入默认值），装备框按 2 倍渲染。
- 测试改读卡面的实时状态；截图 `just shots` 加了卡牌一览（`cards_*`，和样稿对应）和用到卡牌的各界面。
- 问题记录：`_draw` 里 `load()` 的纹理没人持有，函数结束就被释放，画出来是白块；改为静态缓存。

### PR 3 图鉴与关卡选择（PR #17，已合并）

- 图鉴：左侧筛选栏（搜索、类型、星级、种族、时机、基础技能、特殊技能多选下拉），右侧网格上下滚动，顶部张数、已选条件、排序、重置；点卡放大加词条说明（`CardZoom`）。卡牌直接用 `CardFace`，缩放按网格宽度算。
- 关卡选择：标签页、一行三个关卡（`LevelTile`）、展开详情（敌方阵容 `UnitPortrait`，放不下时左右拖动）；"已通关"的样式做好了，等进度存档。
- 两个界面都按画布宽度布局（1920 和 2376 都截图看过），PR 5 改为 `expand` 时不用再改。
- 换上新背景（图鉴、关卡选择）；主题加了筛选勾选块、分组标题、已选条件标签、搜索框、下拉、侧栏、详情面板、弹出面板，标题字体加了字间距。

- 测试：冒烟流程改为检查图鉴的筛选、排序、放大和关卡详情的展开、收起；删掉旧的翻页测试。

### PR 4 构筑阶段与科研模式（PR #18，已合并）

- 布阵界面共用 `components/board/`：7 列布局（`BoardLayout`）、拖放（`BoardDrag`：抬起发光、原位影子、卡位高亮、点一下、悬停或长按看卡）、阵营旗帜、放大查看；卡位 `CardSlot` 自己画（虚线框加位置号、未解锁、高亮、选中）。
- 构筑阶段：对方、我方、手牌三行，右列关卡名、上场计数、开始战斗、紧凑模式；手牌占满一行、放不下时叠压；拖到队列上方时卡牌变成队列的样式；至少上场一个角色，否则弹通知对话框。关卡数据可以写 `slots` 限制卡位数。
- 科研模式：两排卡位、右列按钮（交换双方、清空全部弹确认对话框）、下面的选卡区（标签页、星级和种族筛选、搜索、横向滚动、点卡或往上拖卡）；去掉旧的下拉菜单。
- 紧凑模式：两个界面共用一个开关；构筑阶段手牌放大，科研模式选卡区放大。
- 卡牌：拖动时金色光晕和投影，叠压的手牌带投影；卡牌移动改为可以打断（拿起正在归位的卡不会被拉回去）。
- 换上新背景（作战桌）；删掉旧卡槽图、纯色背景、旧的输入管理和选卡下拉；战斗界面先隐藏空卡位（PR 5 重做）。
- 问题记录：项目开了"鼠标模拟触摸"，PC 上 `is_touchscreen_available()` 也是真，悬停和长按改为按平台判断。
- 测试：冒烟流程加了科研模式的选卡和拖放规则；另外用模拟的鼠标事件试过真实拖动（手牌到卡位、选卡区到卡位、悬停、长按）。

### PR 5 战斗界面（PR #19）

- 新布局：两排卡占满宽度，中间一带是交战位标记、状态（开始战斗 / 阶段名和计数 / 胜负、原因、返回）、速度和跳过；换上浮空岛决斗场背景。
- 出列的卡发光，交战位的卡红框；出列、对撞的距离按两排的空隙算，缩放改小（节奏和特效之后单独设计，飘字还是旧样式）。
- 点卡查看 `CardDetail`：大卡（实时状态）加拆开的角色卡、装备卡；去掉悬停放大 1.7 倍。
- 拉伸改为 `expand`；主题改为项目全局主题，各界面不再单独设置；删掉 `card_manager.gd`、`load_background.gd`。
- 主题重建是确定的：下拉箭头、空图标改为 `ui.py` 生成的贴图（之前每次重建都有随机 ID 的 diff）。
- 截图改为画在固定大小的视口里：手机宽度（2376）也是原尺寸，不受屏幕大小限制。
- 测试：回放检查加了胜负文字和点卡查看的战斗力。
- 用户试用后的调整：科研模式"全部星级"不起作用（绑定的数组被后来的勾选改掉）；战斗的状态放到页面正中，大字的字间距补齐后居中；关卡点一下直接进入，点箭头才展开详情；构筑阶段加"整理手牌"；看卡的放大卡改到卡的上方（不挡手牌）、大小按被查看的卡算；更高的屏幕（截图加了高度参数，看过 16:10 和 4:3）：多出来的高度给手牌、选卡区，战斗两排的空隙有上限，主菜单上下居中。
