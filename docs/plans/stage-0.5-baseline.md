# 阶段 0.5 计划：行为基线测试与规则修复

> **状态**：待用户确认。
> 确认后开 issue「阶段 0.5：行为基线测试与规则修复」，在分支 `stage-0.5-baseline` 上开发，通过 PR 合并。

## 目标

1. 建一套一键运行的测试，记录**现在**的战斗结果。之后整理和重构时，用它证明行为没变。
2. 修掉已经确认的规则问题。每项修复的影响都可见、可核对。
3. 弄清两个关卡现在有几个解，修复后又有几个。

**不在本阶段做**：

- 改目录、命名、数据格式（阶段 1）；
- 抽出战斗核心、实现湮灭（阶段 2）；
- 修 UI 小 bug（阶段 1 顺手修）。

## 1. 测试设施

| 文件 | 作用 |
|---|---|
| `justfile` | `just test` 全部测试、`just smoke` 冒烟测试、`just record` 重录基线、`just levels` 枚举关卡解、`just run` 运行游戏 |
| `tests/run_tests.gd` | 测试入口（无头 SceneTree 脚本）：汇总结果，有失败时退出码非 0 |
| `tests/battle_harness.gd` | 给定双方阵容跑一场战斗，返回胜负和双方幸存单位的战力。复用现有战斗场景，关闭动画 |
| `tests/golden/battles.jsonl` | 战斗黄金用例，一行一条，方便看 diff |
| `tests/tools/record_golden.gd` | 用当前引擎重录期望值，并列出与旧值不同的用例 |
| `tests/tools/level_solutions.gd` | 枚举关卡的全部摆法，输出解 |
| `tests/smoke_test.gd` | 冒烟流程 |

- Godot 路径默认是 `/Applications/Godot.app/Contents/MacOS/Godot`，可以用环境变量 `GODOT` 覆盖。
- 现有战斗场景约 30 场/秒，`just test` 预计半分钟左右。

## 2. 黄金用例

每条用例包含：编号、分组、双方阵容、期望结果（胜负加双方幸存单位的战力）、备注。

| 分组 | 内容 | 数量 | 期望值来源 |
|---|---|---|---|
| rule | 每个词条、时机、装备叠加、判死、平局各 1–3 条 | 约 25 | 手算，再与引擎核对；不一致先查清原因 |
| docx | `战斗流程.docx` 里的例子 | 1 | 文档 |
| matrix | 1★ 同名卡 n 对 n（n = 1–3） | 75 | 录制 |
| level | 两关的默认摆法，以及枚举出的全部解 | 若干 | 录制 |
| random | 固定种子的随机对局：1–7 人，1–2★ 角色，60% 带装备 | 300 | 录制 |

**镜像检查**：每条用例交换左右再跑一次，结果必须镜像对称。修复反噬前已知不对称的用例单独标出，修复后应当全部消失。

## 3. 冒烟测试

- **科研模式**：主菜单 → 科研模式 → 设置阵容 → 开始战斗 → 跳过 → 返回 → 主菜单。
- **闯关**：关卡选择 → 两关的布阵界面各加载一次 → 用默认摆法开始战斗 → 返回。
- **图鉴**：翻页，按角色、装备、星级、关键词筛选。
- **通过标准**：流程走完，日志里没有 `SCRIPT ERROR` 或 `ERROR`。

## 4. 修复顺序（每项一个提交）

| # | 内容 | 预期影响 | 验证 |
|---|---|---|---|
| 1 | 建基线（不改游戏代码） | — | 全部通过 |
| 2 | 跳过时战前阶段不再真实等待 | 只影响时长 | 结果不变 |
| 3 | 平局：新增"连续 20 轮无人阵亡" | 原本不会结束的对局变成平局 | 新增一条无限战斗用例。这条用例不用圣水，因为第 7 步会改圣水 |
| 4 | 反噬：双方都结算，走伤害流程，所有反噬词条都结算 | 含反噬的用例 | 结果变化的用例里都必须有豪猪或尖刺拳套；镜像检查全部通过 |
| 5 | 死亡单位一次性移除 | 现有卡牌触发不到 | 直接构造"相邻两个单位同时阵亡"的单元测试 |
| 6 | 多个坚固求和 | 现有卡牌触发不到 | 单元测试 |
| 7 | 圣水改为仅战前时机，+2 战力 | 含圣水的用例 | 结果变化的用例里都必须有圣水 |
| 8 | 关卡复核 | — | 两关的解数量和通过率，修复前后对比 |

每次修复后用 `just record` 重录基线，工具会列出结果变化的用例。我逐条核对都在预期范围内后再提交。PR 描述里附每一步的变化统计。

## 5. 关卡复核

- **枚举范围**：玩家的所有摆法，包括只上部分角色、装备可以不用。相同的卡互换算作同一种摆法。
- **规模**：猪突猛进约 900 种摆法，虎虎生风更少；每关约半分钟。
- **输出**：解的数量、每个解的具体摆法、通过率。记录到新建的 `docs/design/levels.md`，供阶段 4 设计关卡参考。
- 你记得去掉对称后大约有 1–4 组解。修复反噬后，如果猪突猛进的解数变化很大，再一起讨论怎么调这一关。
