## 2. 这一页是什么

冒险模式（单人）每回合的备战页面：买牌、卖牌、升级、摆阵，然后开战。以后 PVP 也用它。

- 三条横带：上排商店（只放牌），中间我方队列，下排手牌。上排不显示对方，也不要阵营旗帜。
- 队列最多 7 个卡位，按等级解锁：1–7 级是 4/5/5/5/6/6/7 个，最左是交战位。**队列中间可以留空位**（战斗时自动往前补）。能用的空位只画虚线框，不写序号；没解锁的画锁和"N 级解锁"。
- 手牌张数不限。放不下时**先整排缩小、再叠压**：先缩到约 0.8 倍（手机上 9 张以内能并排），还放不下再依次叠压，每张至少露出约七成，居中的卡名要完整；再多可以继续缩到商店牌的大小（0.68 倍）。卡面本身不改。手牌里有三种东西：角色、装备、带着装备的角色（见 4.5）。

## 3. 布局

### 3.1 左上角

- 一个**菜单按钮**（齿轮），代替返回箭头。紧凑模式的开关在设置里，这一页不再放。
- 点开是**屏幕中间的对话框**（用现有页面的对话框样式，整屏压暗），三个按钮：继续、设置、返回主菜单；右上角叉、点框外关闭。
- 点"返回主菜单"要再确认一次，写明**这一局的进度会丢弃**（中途存档以后再做）。
- 以后在菜单里加"导出阵容码"（打开现有的阵容码面板，只导出场上的队列）。
- **左下角预留**：以后放玩家头像，点开看天赋等信息；现在空着，手牌的左边界已经让出这一块。
- 菜单按钮下面是**收起 / 展开商店**的按钮（左边这一竖条放这两个）。商店收起后这两个按钮位置不变，队列让出这一竖条。

### 3.2 商店（上排）

- 常驻在上排，只占上排的高度；可以收起成一条细栏，队列和手牌相应变大。
- 一次 6 张：4 张角色、2 张装备，中间一道分隔。**买走的位置留空（虚线框），不补**，到下次刷新。
- 卡的大小用 A：缩小的完整卡（约 0.68 倍）。
- 每张牌带的信息：
  - 价格：卡内左上角一枚金币写价格，压住星级（价格等于星级，1–5 金币）。买不起：卡变暗，金币变灰、数字变红。
  - 下面一行"已有 N ▮B/C"：N 是自己场上加手牌有几张（觉醒的算 3 张），实时变；B 是这一批商店刷出来时牌库里这种牌的张数（含这一张，买了不变），C 是这种牌的总张数。
  - 已有 2 张时只把数字 2 变黄，不写别的提示。
- 锁定后商店的边框变蓝。
- **收起后的细栏**：左边是这批牌的简写（价格金币 + 卡名，角色和装备之间一道分隔），接着是刷新、锁定，右边是金币、利息、等级、经验条、升级。细栏里的简写点一下也是买。

### 3.3 经济区（右上，和商店同高）

三行，尽量用图标：

1. 金币数；右边三枚利息金币：到了 10/20/30 就亮，下一枚按离下一档的进度从下往上涂金色。下面一行小字只写"利息 +N"。
2. 等级（菱形）、经验条（虚线段是下回合白送的经验）、**升级按钮**（箭头 + 价格，一次升一整级）。三种状态：钱够是金色；钱不够变灰、价格变红；满级写"满级"，经验条整条变金色。不提示升级会不会掉利息档。
3. **刷新**（价格，每回合第一次免费时写"免费"）、**锁定**（锁上后下回合不自动换一批）。

各星级的概率不常驻显示。点"等级菱形 + 经验条"这一整块，弹出概率表：每行一个等级，上场人数、1–5★ 的概率、升到下一级要的经验（7 级写满级）；当前级金色底、下一级蓝色底；右上角叉、点框外关闭。

### 3.4 战斗区（右下，手牌旁边）

回合数；查看对手、冒险事件、整理手牌三个图标按钮排成一行（弹窗这次不画，先占位置）；"开始战斗"。不写上场人数。

### 3.5 手机上的点击范围

手机上每个按钮的**点击范围不小于 110 像素**（约 7 毫米，相当于 44pt），图形可以比点击范围小。PC 不受这条限制。具体到：

- 经济区第 2、3 行高 110；升级、刷新、锁定都够 110。
- 战斗区的三个图标按钮各 110。
- 左上角的菜单、收起两个按钮各 110。
- 细看面板和概率表的叉：图形不变，点击范围扩到 110。
- 细看面板的"原版 / 觉醒后"切换加高到约 90，点大图也能切换。
- 收起后的细栏整条加到约 100 高。

### 3.6 手机的安全区

有刘海、圆角、底部横条的手机，屏幕边缘有一圈不好点或被挡住。样稿按下面的数留（按 iPhone 横屏估的；实现时从系统读实际值）：

- **左右各约 120–150 像素、底部约 50 像素**之内不放按钮、文字、图标，判定范围也不算在里面。
- 背景和色块可以铺到边缘：卖出、使用两条的底色可以贴边，字、图标和判定范围在安全区里面。
- 左上的齿轮和收起按钮、右下的开始战斗、贴底的手牌都往里收。横向因此少 250–300 像素，商店、队列、手牌跟着重新排，卡的大小可以相应调整。
- 加一个显示安全区的参数（像 `hit=1` 那样），出带标注的图。PC 没有安全区。

## 4. 交互

### 4.1 查看

- **快看**：PC 悬停约 0.15 秒，手机长按约 0.4 秒，在卡旁放大，移开或松开就消失。PC 上悬停时按住 Shift，临时显示觉醒后的样子（已觉醒的显示原版）。
- **细看面板**：左边大卡，角色上面有"原版 / 觉醒后"切换；右边卡名、星级种族、已有和牌库，觉醒后多一行"觉醒：变了什么"，下面是时机和词条的说明；右上角叉、点框外关闭。
  - "觉醒：变了什么"只写数值的变化（如"支援 13 → 20""战斗力 3 → 6"），不写"翻倍"之类的说法（觉醒不一定是两倍）。
  - 带装备的角色：大图是合起来的样子，右边多一行"组成"（角色、装备两张小卡，点开看单张）。
- 打开细看面板的办法：
  - **手牌、场上的牌**：点一下。
  - **商店的牌**（点一下是买，所以另有入口）：手机长按出快看后，**原地松开**就固定成细看面板（移动则转成拖动）；PC 右键。
- 面板里的动作按钮：
  - 商店的牌：**没有按钮**（要买就关掉面板点牌）。
  - 手牌的牌：上场、卖出 +1；带装备的角色多一个"拆开"，卖出时写"装备回手牌"。

### 4.2 买

- **点一下商店的牌就买，进手牌**（展开的商店和收起的细栏一样）。商店没有双击。
- 也可以拖：拖到手牌区进手牌；角色拖到空卡位直接上场，拖到有人的卡位是替换；装备拖到场上的角色身上直接装备。
- 买不起的点了不买、拖不动，牌抖一下。

### 4.3 手牌的点击

- 点一下打开细看面板，**立刻打开、不等待**（约 0.12 秒淡入）。
- **约 0.3 秒内在同一位置再点一下（双击）：角色上场到第一个空卡位**，面板关掉。没有空位时牌抖一下，提示"没有空位"。装备双击没有作用。以后能直接使用的牌，双击就是使用。

### 4.4 拖动

- 按下并移动超过阈值开始拖动；长按出了快看后再移动，也转成拖动。
- 拖动中：一张小卡跟手（手机在手指上方 60 像素，PC 在光标处，贴近屏幕边时不出屏幕；从商店拖的带着价格金币）；这张牌的大图放在上排、离手指远的一侧，下沿压一条"当前卡牌"；原位置留半透明的影子。
- 拖动一开始就标出这次能放的所有区域，其余稍微压暗，战斗区收起来：
  - **卡位**：金色虚线，动作名写在卡位中间偏下（空位"上场"、有人"替换"、装备拖到有人的位置"装备"），未解锁的不亮；手指在哪个上面，哪个实线发光、字变大。
  - **手牌区**：下排，银色虚线，写"放回手牌"（从商店拖是"放进手牌"）。
  - **卖出、使用**：只在拖手牌、场上的牌时，从右下角、左下角弹出，是两条窄条，高度和手牌那一排一样（安全区里面的宽度手机 150、PC 140；手机上底色再往外铺到屏幕边）。右下红色"卖出 +1"（觉醒的 +3），左下青色"使用"，不能用时灰色"不能直接使用"。从商店拖时没有这两块。
  - **手牌区和两个角之间各留约 60 像素的空带**，松在空带里算放回手牌（防止整理手牌时误卖、误用）。手牌平时也只排在这个范围里，拖起来时不会有牌压在两条下面。
  - **能直接使用的牌**：整屏铺一层淡青，上排写"松开就使用"；松在空白处（不是卡位、不在两角）等于使用。普通角色没有这一层。
- 取消：拖回原处松手；PC 上右键或 Esc。

### 4.5 卖、用、装备

- 卖：场上、手牌的牌拖到卖出区，或者在细看面板里点"卖出"。卖带装备的角色，装备回手牌。
- 用：以后会有"直接使用"的牌；样稿里用示意牌"经验卷轴"。
- 装备可以拖到另一个角色身上换过去，原来的装备回手牌。
- 手动把角色从场上拖回手牌：角色和装备自动拆开，变成手牌里的两张。
- 用手牌里的角色替换场上的角色：被换下来的带着装备一起回手牌，在手牌里是一张带装备的角色（卡面上有装备小卡，那张装备牌叠在后面、往右上错开露出边框）；在手牌里拖动它一下就拆开。

### 4.6 快捷键（PC，以后可以在设置里改）

| 键 | 作用 |
|---|---|
| Shift（按住） | 悬停的牌显示觉醒后 / 原版 |
| F | 购买悬停的商店牌 |
| E | 卖出悬停的牌 |
| D | 刷新商店 |
| R | 升级 |
| Q | 锁定 |
| Tab（按住） | 显示快捷键 |

平时不标键名。按住 Tab：画面压暗，有快捷键的按钮留在暗层上面、贴键帽，悬停的牌上写它能用的键，队列中间一张总表（键盘的键之外再列鼠标的操作：左键买商店的牌、右键细看商店的牌、双击手牌的角色上场）；松开就收起。（实现时要关掉 Tab 切换焦点的默认行为。）

## 5. 觉醒

### 5.1 规则（和界面有关的部分）

- 场上加手牌凑够三张相同的角色，**自动**合成一张觉醒的，不能选择不合。
- 合成后的牌落在场上最靠前那张的位置；场上没有就在手牌。保留最靠前那张的装备，其余的装备回手牌。**另外两张原来的位置空出来，不往前补。**
- 觉醒的牌数值更高（每张牌不一样，所以要有"觉醒后"的查看），卖出 3 金币。

### 5.2 卡面

- 边框不变。蒙版用流金（弱一点，不扫光）：盖在卡图上、边框和文字下面；框内一圈淡金光，卡图偏暖的淡金色，一片很淡的斜向柔光慢慢来回移动，金色光点往上飘。
- 卡名后加星号（`密林射手*`），整个卡名换成金色。
- 觉醒版和原版并排要一眼分得出，缩小到商店、队列的大小也分得出。

### 5.3 合成的时机和动画

- 逻辑立刻生效，动画不挡操作：买到第三张的瞬间就已经合成，可以马上接着刷新、买下一张。
- 买到第三张，约 0.6 秒：买来的牌从商店弹起、场上两张亮起 → 三张沿弧线飞向落点 → 叠在一起，金光收拢 → 觉醒的牌出现，放大再落回。
- 一次得到几张牌（天赋、拍卖、事件），约 1.2 秒：牌依次飞进手牌（间隔 100 毫秒）；触发合成的那张到位后再播合成。

## 7. 验收看什么

- 手机上不点开也能看清：每张商店牌是什么、多少钱、已有几张；自己有多少金币、离升级和利息差多少。
- 手机上每个按钮都点得准（点击范围不小于 110），都在安全区里面。
- 买牌时我方队列和手牌始终看得见。
- 拖动时不用猜：每个区域是什么、现在能不能放。
- 觉醒的牌在任何大小下都认得出。
- 和现有页面（科研模式、图鉴、战斗）是一套东西。

## 8. 没定的

- 中途退出后这一局的进度要不要保留（存档；现在按丢弃）。
- 误买、卖错要不要补救（撤销，或本回合买的牌原价退）：等实际试玩后再定。
- 双击场上的角色要不要回手牌（现在不做：误触会把装备拆开）。
- PVP 时"牌库"会透露别人拿了什么，到时再定是否保留。
- 以后价格如果不等于星级（天赋、拍卖），商店牌上被金币压住的星级怎么显示。

设计者有更好的做法可以直接出一版对比，在说明里写清楚和这份文档哪里不同、为什么。
